# リールサムネイル用 背景写真素材

`reel-thumbnail.html` テンプレートは `bg` パラメータに画像パスを渡すと、
その画像を背景に使用します(暗めのトーンの勉強机・コーヒー・キャンドル等)。

## 現状
このフォルダにはまだ実ファイルが入っていません。
`bg` が指定されない場合は、テンプレート側でグラデーションのプレースホルダー
背景にフォールバックするため、素材が無くてもパイプラインは止まりません
(ただし成果物としては未完成なので、プレースホルダーのまま公開しないこと)。

## 用意してほしいもの(益田さん対応)
- 著作権フリー・商用利用可の写真素材(勉強机/コーヒー/キャンドル等、暗めのトーン)
- 推奨: 1080x1920以上、縦長(9:16)
- このフォルダに `study-desk-01.jpg` のような分かりやすい名前で追加してください

## 追加後の使い方
`02_departments/creative/drafts/<task_id>.spec.json` の `thumbnail.bg` に
このフォルダ内のファイルへの相対パス(例: `03_assets/images/backgrounds/study-desk-01.jpg`)
を指定すると、次回のcreative-pipeline実行時に自動で使用されます。
複数枚あれば、投稿内容に合わせてClaude(creative担当)がそのつど選定します。
