# 模試の結果で一喜一憂しない親のスタンス ― 数字より見てほしいこと

## 導入

模試の結果が返ってきた日、保護者様のご家庭はどんな空気になっているでしょうか。

判定がよければ「よかったね!」と喜び、悪ければ「大丈夫?」と心配になる——それ自体はごく自然な親心です。ですが、結果を見た瞬間の表情や第一声を、お子さまは実はとてもよく見ています。**保護者様が点数や判定に一喜一憂すればするほど、お子さまも「結果がすべて」という捉え方から抜け出せなくなる**、という側面があるのです。

一回の模試の結果に振り回されず、かといって無関心にもならない。そんな距離感で模試と付き合うには、どうすればいいのでしょうか。今日は、心理学の知見を交えながら、模試の結果との向き合い方についてお話しします。

## 理論的背景:結果への反応が、子どもの捉え方をつくる

教育心理学に「帰属理論」という考え方があります。これは、人が成功や失敗の原因を何に求めるか(=何に「帰属」させるか)によって、その後の行動やモチベーションが変わってくる、という理論です。

模試の結果が悪かったとき、それを「自分の頭が悪いから」という**変えられない原因**に帰属させてしまうと、子どもは「どうせやっても無駄だ」と努力そのものを諦めやすくなります。一方で、「今回は時間配分の練習が足りなかったから」という**変えられる原因**に帰属させられれば、次に向けた具体的な行動につながります。**保護者様の第一声は、子どもがどちらに帰属させるかを大きく左右します。**

もうひとつ重要なのが、スタンフォード大学の心理学者キャロル・ドゥエックが提唱した「マインドセット理論」です。能力は生まれつき固定されていると考える「固定マインドセット」と、努力次第で伸びると考える「成長マインドセット」があり、**周囲からの声かけの積み重ねが、どちらのマインドセットを育てるかに影響する**ことが分かっています。結果や才能を褒める声かけを繰り返すと固定マインドセットが強まりやすく、取り組み方や工夫のプロセスを認める声かけを繰り返すと成長マインドセットが育ちやすい、とされています。

模試はあくまで、今の学力を測る「途中経過」のひとつの断面にすぎません。**保護者様が数字そのものより、そこに至るプロセスに目を向ける姿勢を見せることが、子ども自身の結果との向き合い方を形づくっていきます。**

## 具体的な実践ステップ

理論を踏まえて、模試の結果が返ってきた場面で今日から意識できる4つのステップをご紹介します。

### ステップ1:結果を見る前に「今回の目標」を思い出す

判定や偏差値という「数字」だけを見ると、前回との比較や周りとの比較に意識が向きがちです。まずは、今回の模試で何を目標にしていたかを一緒に振り返りましょう。

- **NG例**:結果を見るなり「今回はどうだった?」と数字から聞く
- **OK例**:「今回、自分の中でどこを試したかった?」と目的から聞く

**目標に対してどうだったかという視点があると、判定だけでは見えない「できるようになったこと」に気づきやすくなります。**

### ステップ2:点数ではなく「解き方のプロセス」に注目する

同じ点数でも、時間が足りずに解けなかったのか、そもそも解法が分からなかったのかでは、次にやるべきことがまったく違います。

- **NG例**:「英語が思ったより低かったね」と結果だけを話題にする
- **OK例**:「この大問、時間が足りなかった? それとも解き方に迷った?」

**プロセスに焦点を当てた問いかけは、成長マインドセットを育てる声かけそのものです。** 点数への反応より先に、解き方への関心を示してみてください。

### ステップ3:一喜一憂を「感情の実況」から「事実の確認」に変える

結果を見た瞬間、「やった!」「え、これは…」といった感情がまず声に出てしまうのは自然なことです。ただ、その感情の実況を挟む前に、事実を一緒に確認する習慣をつけると、場の空気が変わります。

- **NG例**:結果を見た瞬間に「え、下がってるじゃない」と表情に出す
- **OK例**:「前回と比べて、この単元は伸びてるね。ここはどうだった?」

**保護者様が落ち着いて事実を確認する姿を見せることが、子ども自身の「一喜一憂しすぎない捉え方」のお手本になります。**

### ステップ4:悪い結果の時こそ、次の一手を一緒に決める

判定が厳しかったときほど、励ましの言葉をかけたくなりますが、抽象的な励ましだけでは次につながりません。

- **NG例**:「次は頑張ろうね」とだけ声をかけて終わる
- **OK例**:「この単元、来週どこから手をつける?」と具体的な行動を一緒に決める

**次の行動が一つでも決まれば、悪い結果も「終わり」ではなく「通過点」に変わります。** 保護者様の役割は、結果を評価することではなく、次への橋渡しをすることです。

## フレーズ変換集

模試の結果を見た瞬間、とっさに出てしまいがちな言葉を、意識して変換するだけで、お子さまとの向き合い方は大きく変わります。ぜひ使ってみてください。

| よく言ってしまう言葉(NG) | 変換後のひとこと(OK) |
| --- | --- |
| 今回はどうだった? | 今回、自分の中でどこを試したかった? |
| 前より下がってるじゃない | この単元は伸びてるね、ここはどうだった? |
| なんでこんな点数なの | この大問、時間が足りなかった? 解き方に迷った? |
| 次は頑張ろうね | この単元、来週どこから手をつける? |
| 判定Cか、厳しいね | 目標に対して、あとどこを埋めればよさそう? |
| 周りはもっと取れてるらしいよ | 前回の自分と比べて、変わったところはある? |

**共通しているのは、「数字への反応」ではなく「プロセスへの問いかけ」に変えているという点です。** すべてを一度に変える必要はありません。次に結果を見せてもらう場面で、ひとつ試してみてください。

## まとめ

模試の結果は、お子さまの努力の全てを映し出すものではありません。それでも判定や点数という分かりやすい数字を前にすると、保護者様も思わず一喜一憂したくなるのは当然のことです。それでも、**結果そのものより「どう向き合うか」に目を向けるだけで、お子さまが次の模試に向かう姿勢は少しずつ変わっていきます。**

大切なのは、良い結果を取り続けることではなく、結果とどう付き合うかを自分なりに身につけていくことです。それは、目先の判定以上に、この先ずっと役立つ力になります。

私たち学ジムでも、模試の結果を「終わり」ではなく「次への材料」として一緒に振り返ることを大切にしています。**勉強を、筋トレのように"続けられる仕組み"に変える**——そのために、コーチが一喜一憂の波に流されず、結果から次の「継続の負荷設定」を一緒に組み立てています。ご家庭だけで結果と向き合うのが難しいと感じるときは、隣で一緒に振り返ってくれる相手がいるだけでも、模試との付き合い方は変わるものです。

今日ご紹介した向き合い方を、ぜひ次の模試返却の日から、一つで大丈夫ですので試してみてください。保護者様とお子さまにとって、模試の結果を見る日が、少しでも前向きなものになりますように。
