# テスト期間中、毎晩どう過ごす? ― 結果は「気合」ではなく「回復」で変わります

## 導入

定期テストは、1日で終わらないことが多いものです。2日目、3日目と続くテスト期間中、保護者様はこんな場面に心当たりがないでしょうか。

- 1日目の出来が悪かったと落ち込んで、帰宅後に口数が減っている
- 夜遅くまで起きていて、朝は食欲がない
- 「大丈夫?」と声をかけたら、「うるさい!」と返された

心配だからこそ、何かしてあげたい。でも、何をしても裏目に出る気がする。私も、保護者様から「テスト期間中は何を言っても空回りします」というご相談を何度も受けてきました。

先に結論をお伝えします。**テスト期間中に家庭ができる最大のサポートは、勉強を見ることではなく、「毎晩しっかり回復できる環境」を整えることです。** 点数を左右するのは、気合ではなく回復力。この記事では、期間中の毎晩・毎朝にできることを、NG/OKの具体例つきでお伝えします。

## 理論的背景:なぜ「回復」が結果を左右するのか

### 疲れた脳は、思い出す力が落ちます

テストは、覚えた内容を「思い出す」作業の連続です。睡眠不足や疲れがたまると、集中力や注意力が下がり、**知っているはずの問題でもミスが増えやすくなる**ことが、睡眠と認知機能の研究で知られています。テスト期間の後半ほど、家庭での回復が効いてきます。

### 1科目目の「失敗感」は、次の科目に引きずられます

心理学では、直前の失敗体験が次の場面での不安や自己評価の低下につながることが指摘されています。**終わった科目を振り返って落ち込むほど、次の科目に使える力は減ってしまいます。** 「終わったことは切り離す」環境づくりが、親にできる大切な役割です。

### 「見守られている」感覚が、緊張を和らげます

コーチングでは、答えを教えることより、**安心して話せる関係**が本人の力を引き出すと考えます。「話を聞いてほしいとき」と「そっとしてほしいとき」は、お子さんによって違います。その見極めと確認が、期間中の関わりの鍵になります。

## 実践ステップ

### ステップ1:帰宅直後は「出来」を聞かず、「お疲れさま」から始める

帰ってきてすぐの「どうだった?」は、お子さんにとって採点を迫られる一言になりがちです。

- **NG:** 「今日のテスト、どうだったの? できた?」
- **OK:** 「お疲れさま。おやつあるよ。話したくなったらいつでも聞くね」

**話すかどうかを、お子さんに選ばせる**ことが安心につながります。

### ステップ2:終わった科目の「答え合わせ」は期間後に回す

終わった科目の反省は、残りのテストには1点も貢献しません。

- **NG:** 「さっきの数学、どこ間違えたの? 見せてごらん」
- **OK:** 「数学は終わったね。明日の科目で、今夜やっておきたいことは何かある?」

**答え合わせは、全科目が終わってから。** これを家庭のルールとして先に決めておくと、親子ともに迷いません。

### ステップ3:夜の勉強は「翌日の科目だけ」「時間を決めて」

期間中の夜は、前日記事でもお伝えした通り「増やす」のではなく「絞る」のが原則です。ここに、学ジムが大切にしている「継続の負荷設定」の発想を使います。**期間中は負荷を上げる時期ではなく、維持して回復する時期**です。

- **NG:** 「明日の科目だけじゃなくて、他も見直しておいたら?」
- **OK:** 「明日の科目に絞って、○時までにしよう。そこから先は回復の時間だよ」

### ステップ4:朝ごはんと水分を「勉強の道具」として整える

食欲がない朝に、無理に食べさせようとすると、かえってプレッシャーになります。

- **NG:** 「ちゃんと食べないと頭働かないよ! 全部食べなさい」
- **OK:** 「バナナとヨーグルトだけでも持っていく? 飲み物は水筒に入れておくね」

**量より「食べやすさ」を優先**し、食べられるものを用意しておきましょう。

### ステップ5:出来が悪かった日は、「事実」と「感情」を分けて受け止める

1日目の出来に落ち込んで帰ってきたとき、励まそうとして否定してしまうことがあります。

- **NG:** 「大丈夫、そんなに悪くないって。気にしすぎだよ」
- **OK:** 「できなかった感じがして、しんどいよね。……明日は新しいテストだから、今夜ゆっくり休んで切り替えよう」

まず**感情を受け止め、そのうえで「明日は別のテスト」と視点を未来に向ける**。この順番が大切です。

## フレーズ変換集

テスト期間中の場面別に、言い換えをまとめました。スマホのメモに保存して、とっさのときにご活用ください。

| 場面 | NGフレーズ | OKフレーズ |
|---|---|---|
| 帰宅直後 | 「どうだった? ちゃんとできたの?」 | 「お疲れさま。おやつ食べる? 話したくなったら聞くよ」 |
| 出来が悪かったと落ち込む | 「気にしすぎ、大丈夫だって」 | 「しんどいよね。明日は別のテスト。今日はゆっくり休もう」 |
| 終わった科目を振り返っている | 「どこ間違えたの? 見せて」 | 「それは全部終わってから一緒に見よう。今は明日の科目に集中しよう」 |
| 夜更かししている | 「いつまで起きてるの!」 | 「あと30分で区切ろう。寝るのも作戦のうちだよ」 |
| 朝、食欲がない | 「食べないと力出ないよ」 | 「食べやすいものだけ持っていこうか。水筒も入れておくね」 |
| イライラして当たってくる | 「その言い方は何?」 | (一呼吸おいて)「今、余裕ないよね。何か手伝えることある?」 |
| 送り出すとき | 「頑張りなさいよ」 | 「いってらっしゃい。帰ってきたらゆっくりしようね」 |

**全部を変えようとしなくて大丈夫です。** まずは「帰宅直後の一言」だけ、今日から変えてみてください。

## まとめ

テスト期間中、お子さんは、保護者様が思う以上に緊張し、疲れています。そこで必要なのは、追加の勉強や励ましの言葉よりも、**「家に帰れば安心できる」という回復の場所**です。

期間中は、保護者様もつい力が入ってしまうと思います。口出ししたくなる気持ちを抑えるのは、簡単なことではありません。それでも、お子さんの隣で温かい飲み物を用意し、「お疲れさま」と言う。その積み重ねが、残りのテストを乗り切る力になります。どうかご自身を責めず、できることから始めてください。
