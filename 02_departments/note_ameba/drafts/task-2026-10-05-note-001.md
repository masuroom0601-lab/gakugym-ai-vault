# 「勉強しなさい」を言わずに机に向かわせる方法 ― 声かけより先に整えたい「仕組み」

## 導入

夕食後、気づけば子どもはソファでスマホ。「そろそろ勉強したら?」と言いかけて、ぐっと飲み込む。結局、我慢できずに口に出して、不機嫌な空気になってしまう——保護者様のご家庭にも、そんな夜があるのではないでしょうか。

「言わない方がいいのは分かっているけれど、言わなければ本当にやらない」。このジレンマに、多くの保護者様が悩んでいます。私も、そのご相談を何度も受けてきました。

ただ、ここで一つお伝えしたいことがあります。**子どもが机に向かわないのは、やる気や性格の問題より先に、「机に向かうまでの仕組み」が整っていないことが原因であるケースが少なくありません。** 声をかける回数を減らす努力よりも、声をかけなくても動ける環境をつくる方が、ずっと確実です。今日は、そのための考え方と具体的な方法をお話しします。

## 理論的背景:行動は「意志」より「環境」と「きっかけ」で決まる

行動科学では、人の行動は意志の強さだけでなく、**周囲の環境や、行動の「きっかけ」に大きく左右される**と考えられています。大人でも、「ジムに行こう」と決意しただけでは続かず、ウェアを玄関に置いておくだけで行きやすくなる、という経験はないでしょうか。

関連する知見を2つご紹介します。

**1. 実行意図(if-thenプランニング)**
心理学者ピーター・ゴルヴィッツァーらが研究した考え方で、「いつ・どこで・何をするか」を「もしXならYする」の形で事前に決めておくと、行動に移りやすくなるとされています。「勉強しよう」という漠然とした目標より、**「夕食の片付けが終わったら、リビングのテーブルで英単語を10分やる」と具体化した方が動きやすい**のです。

**2. 摩擦(フリクション)の設計**
行動を始めるまでの手間が大きいほど、人は先延ばしにします。逆に言えば、**勉強を始める手間を減らし、スマホを触る手間を少し増やすだけで、行動は変わります。** 意志の力に頼らず、環境の側を整えるという発想です。

さらに、自己決定理論でも、人は「自分で決めた」と感じるときに行動を続けやすいとされています。つまり、**ルールを親が一方的に決めるのではなく、子ども自身が参加して決めることが、仕組みを長持ちさせるカギ**になります。

## 具体的な実践ステップ

ここからは、「勉強しなさい」を使わずに、子どもが自分から机に向かうための4つのステップをご紹介します。

### ステップ1:「始める時間」を、子どもと一緒に決める

「勉強しなさい」が出てしまう最大の原因は、「いつ始めるか」が決まっていないことです。時間が曖昧だと、親も子も毎日そのタイミングを探り合うことになります。

- **NG例**:帰宅後の様子を見て、親が「そろそろやったら?」と声をかける
- **OK例**:「夕食の片付けが終わったら始める」と、子どもと一緒に決めておく

ポイントは、時刻ではなく**「生活の中の出来事」に結びつける**ことです。「19時から」より「お風呂の前に」の方が、日によって生活が多少ずれても崩れにくくなります。**決めるのは親ではなく子ども本人、親は選択肢を示すだけ**にしてください。

### ステップ2:始めるまでの「摩擦」を減らす

机に向かう前の「準備の面倒くささ」は、想像以上に大きなハードルです。教科書を探し、ノートを探し、筆箱を探しているうちに、気持ちは別のものに向かってしまいます。

- **NG例**:机の上が散らかっていて、座ってもすぐに始められない
- **OK例**:今日やる教材とペンを、前日の夜に机の上に出しておく

**「座ったら、すぐ1問目に取りかかれる状態」をつくっておくだけで、最初の一歩はぐっと軽くなります。** 親が準備をするのではなく、「寝る前に明日の分を出しておく」までを子どもの習慣にするのが理想です。

### ステップ3:最初のハードルを「1〜5分」まで下げる

「今日は2時間やる」という目標は、始める前から気が重くなります。最初の目標は、思い切って小さくしましょう。

- **NG例**:「今日は最低でも2時間はやりなさい」と大きな目標を課す
- **OK例**:「まず英単語を5つだけ」と、始めやすい量から入る

人は、一度始めると続けやすい傾向があります。**「始めること」自体を目標にして、その後は本人のペースに任せる**くらいがちょうどいいのです。これは、学ジムが大切にしている「継続の負荷設定」の考え方とも通じます。負荷を最初から上げすぎず、続けられる軽さから始めるのが、長く続くコツです。

### ステップ4:「やったこと」を見える形にして、親は結果ではなく継続を認める

仕組みを続けるには、「やった」という実感が必要です。カレンダーに丸をつける、チェックを入れるなど、**本人が自分で記録できる形**にしておきましょう。

- **NG例**:「今日は何ページ進んだの?」と成果の量だけを確認する
- **OK例**:「今週は5日、机に向かえたね」と、続けられたことを認める

**親の役割は、見張ることではなく、続いていることに気づいて伝えることです。** 勉強の中身や成績に口を出すのは、習慣が定着してからで遅くありません。

## フレーズ変換集

「勉強しなさい」が口から出そうになったとき、こんな言葉に置き換えてみてください。

| よく言ってしまう言葉(NG) | 変換後のひとこと(OK) |
| --- | --- |
| 勉強しなさい | 今日は、お風呂の前と後、どっちにやる? |
| いつまでスマホ見てるの | スマホはここに置いて、5分だけ英単語やってみようか |
| 早く宿題やっちゃいなさい | 今日やるもの、机に出しておこうか。手伝うことある? |
| 今日は何時間やるの? | 今日は最初に何から手をつける? |
| なんでやらないの | やりにくいところ、どこかあるかな? |
| 今日も全然やってないじゃない | 今週は3日できてるね。あと1日、いつならやれそう? |

**共通しているのは、「命令」を「選択肢」や「問いかけ」に変えていることです。** 子どもが自分で選べる余地を残すことが、「やらされている」から「自分で決めた」への切り替えにつながります。

## まとめ

「勉強しなさい」を言わずに済むようにするために、保護者様が変えるべきなのは、子どもの性格や気持ちではなく、**「始めるまでの仕組み」**です。始める時間を決め、準備の手間を減らし、最初のハードルを下げ、続けたことを認める。この4つが整えば、声かけの回数は自然と減っていきます。

最初から全部を完璧にする必要はありません。まずは一つだけ、たとえば「前日の夜に明日の教材を机に出しておく」ことから試してみてください。小さな変化でも、家庭の空気は少しずつ変わっていきます。

私たち学ジムでも、勉強を、筋トレのように**"続けられる仕組み"**に変えることを大切にしています。コーチが隣で、お子さまに合った始めやすさと続けやすさを一緒に設計しています。ご家庭だけで仕組みづくりを進めるのが難しいと感じたときは、第三者の力を借りるのも一つの方法です。

毎日の声かけに疲れていた保護者様が、少しでも肩の力を抜いて、お子さまの「自分から動く瞬間」を見られますように。まずは今夜、できることから一つだけ、始めてみてください。
