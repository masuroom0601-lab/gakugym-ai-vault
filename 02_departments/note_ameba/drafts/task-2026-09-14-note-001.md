# テスト前に「焦り」を見せる子どもに、保護者様ができること

## 導入

テスト直前になると、子どもの様子が急に変わる——そんな経験はありませんか。

部屋を落ち着きなく行ったり来たりする。「もう無理かも」「終わらない」とつぶやく。声をかけても上の空で、いつもより表情が硬い。そんな姿を見ていると、保護者様まで一緒に不安になってしまいますよね。

励ましたほうがいいのか、それとも黙って見守るべきなのか。声のかけ方ひとつで子どもの機嫌が変わってしまうから、つい何も言えなくなる——そんな保護者様のお悩みを、私はこの時期になるとよくお聞きします。

**焦っている子どもに必要なのは、正しいアドバイスよりも先に、気持ちを受け止めてもらうことです。** 今日は、テスト前の焦りとの向き合い方を、心理学の知見も交えながらお話しします。

## 理論的背景:なぜ「焦り」は放っておくと悪化するのか

心理学には、緊張や不安と成果の関係を説明する考え方があります。**適度な緊張感は集中力を高めますが、それが一定の水準を超えると、かえって本来の力を発揮できなくなる**というものです。テスト前の焦りそのものは悪いものではなく、むしろ「頑張りたい」という気持ちの表れです。問題は、その焦りが行き場をなくして膨らんでしまうことにあります。

コーチングや心理学の世界では、「感情を落ち着かせるには、まず感情を認めてもらう必要がある」とされています。**「大丈夫、なんとかなるよ」と結論を急いで伝えるより先に、「そう感じているんだね」と気持ちに言葉を添えてもらうこと**が、子どもの気持ちを落ち着かせる第一歩になります。不安をなかったことにされるより、そのまま受け止めてもらえたほうが、人は次の一歩に進みやすくなるのです。

さらに、子どもの情緒は保護者様の状態に影響を受けやすいことも分かっています。**保護者様自身が落ち着いた声・落ち着いたペースでいることが、子どもの気持ちを整える一番の環境**になります。子どもは、自分の不安をどう扱えばいいか、身近な大人の様子から学んでいくものだからです。

そしてもうひとつ大切なのが、「今、何ができるか」に意識を戻すことです。焦りは多くの場合、「全部終わらせなければ」という漠然とした不安から生まれます。**視界を狭めて、今日・今から取り組める一つに絞ってあげる**だけで、頭の中の混乱は驚くほど整理されます。

## 具体的な実践ステップ

理論を踏まえて、テスト前の家庭で今日から試せる4つのステップをご紹介します。

### ステップ1:アドバイスの前に、気持ちを言葉にして受け止める

子どもが「もう無理」と言ったとき、つい解決策を急いで伝えたくなりますが、その前にワンクッション置くことが大切です。

- **NG例**:「そんなに焦らなくても大丈夫だよ」
- **OK例**:「それだけ本気でやってきたってことだよね」

**気持ちを否定せずに受け止めてもらえた子どもは、そのあとの提案にも耳を傾けやすくなります。** 私が指導現場で見てきた生徒たちも、まず「分かってもらえた」と感じたときに落ち着きを取り戻すことが多いです。

### ステップ2:「全部」ではなく「今できる一つ」に絞る

焦りの正体は、たいてい「やることが多すぎる」という漠然とした感覚です。範囲を狭めてあげましょう。

- **NG例**:「範囲全部、まだ終わってないの?」
- **OK例**:「今日はこのページだけ、一緒に確認しようか」

やることを一つに絞ると、子どもは「これならできそう」という感覚を取り戻せます。**小さくても『これは終わった』という手応えが、次の落ち着きにつながります。**

### ステップ3:保護者様自身が、声のトーンを落ち着かせる

子どもの焦りに引っ張られて、つい保護者様の声も速く・強くなってしまいがちです。まずは深呼吸をひとつ。

- **NG例**:早口で「なんでまだ終わってないの?」
- **OK例**:ゆっくりとした口調で「一緒に、今できることを確認しよう」

**声のトーンとスピードを変えるだけで、部屋の空気そのものが落ち着きます。** 言葉の中身以上に、声の調子が子どもの安心感を左右することは少なくありません。

### ステップ4:テスト後の話は、今しない

不安なときほど、「結果が悪かったらどうするの」という言葉が出てしまいがちですが、これは今の焦りに追い打ちをかけてしまいます。

- **NG例**:「順位が下がったらどうするつもり?」
- **OK例**:「終わったら、好きなもの食べに行こうか」

未来の心配は、テストが終わってから一緒に考えれば十分です。**「今」に意識を戻してあげることが、目の前の集中力を守ります。**

## フレーズ変換集

とっさに出てしまいがちな言葉を、意識して変換するだけで、子どもの受け取り方は大きく変わります。テスト前のワンシーンで、ぜひ使ってみてください。

| よく言ってしまう言葉(NG) | 変換後のひとこと(OK) |
| --- | --- |
| そんなに焦らなくても大丈夫 | そう感じるくらい、頑張ってきたんだね |
| 範囲全部、終わってないの? | 今日はここだけ、一緒にやろうか |
| なんでまだできてないの? | どこまで進んだか、聞かせてくれる? |
| 順位が悪かったらどうするの | 終わったら、ゆっくり休もうね |
| 落ち着きなさい | 一回、深呼吸してみようか |
| 前も同じこと言ってたよね | 今できることを、一緒に確認しよう |

**共通しているのは、「評価」ではなく「今の気持ちに寄り添う」形にしているという点です。** すべてを変える必要はありません。テスト前日だけでも、ひとつ試してみてください。

## まとめ

テスト前の子どもの焦りは、なくそうとするものではなく、そばで受け止めてあげるものです。

**保護者様が落ち着いて隣にいてくれるだけで、子どもは「一人で抱え込まなくていい」と感じられます。** それは、テストの点数そのものよりも、ずっと長く子どもの中に残る安心感になります。

私たち学ジムでも、テスト前の不安との向き合い方を大切にしています。**勉強を、筋トレのように"続けられる仕組み"に変える**——そのために、コーチが「今できること」を一緒に整理し、無理のない「継続の負荷設定」でお子さまの気持ちに寄り添っています。ご家庭だけで抱え込まず、隣で一緒に整理してくれる相手がいるだけでも、テスト前の空気は変わるものです。

今日ご紹介した声かけを、ぜひ一つからで大丈夫ですので、試してみてください。テスト前の数日間が、保護者様とお子さまにとって、少しでも穏やかなものになりますように。
