# テスト計画を立てても続かない子への向き合い方 ― 「続かない」は意志の弱さではなく「設計」の問題です

## 導入

期末テストの4週間前。お子さんが「今回はちゃんと計画を立てる!」と、カラフルなペンで予定表を作り上げた。ところが3日後、予定表は机の隅に追いやられ、いつもの「テスト前の一夜漬け」に逆戻り——。

そんな姿を見て、つい「また三日坊主なの?」「計画倒れじゃない」と口にしてしまった保護者様も多いのではないでしょうか。私も、同じご相談を本当に数多く受けてきました。

先に結論をお伝えします。**計画が続かない原因のほとんどは、意志の弱さではなく、「計画の作り方」と「立て直し方」にあります。** そして、保護者様の関わり方一つで、お子さんが計画を続けられるかどうかは大きく変わります。この記事では、NG例・OK例つきでその方法をお伝えします。

## 理論的背景:なぜ計画は続かないのか

### 人は自分の作業時間を短く見積もります

心理学には「計画錯誤」という現象があります。人は、自分がやる作業にかかる時間を、実際より短く見積もりがちだという研究です。これは大人でも起こります。つまり、**お子さんが無理な計画を立てるのは、怠けているからではなく、誰にでも起きる脳のクセ**です。

だからこそ、「計画を立てる力」より **「計画を直し続ける力」** が大切になります。

### 「いつ・どこで・何をするか」を決めると実行率が上がります

行動科学では、「もし〇〇になったら△△する」と具体的に決めておく「実行意図」が、行動の実行率を高めることが知られています。「毎日2時間勉強する」より、「夕食後、リビングで英単語を15分」のほうが、はるかに動き出しやすいのです。

### 計画が崩れたときの反応が、次の意欲を決めます

一度予定が崩れると、「もう全部ダメだ」とやめてしまう現象は珍しくありません。ここで保護者様が責めると、お子さんは「計画=怒られるもの」と学習してしまいます。コーチングの視点では、**失敗を責めずに「どう直す?」と問いかける**ことが、自分で調整する力を育てます。

## 実践ステップ

### ステップ1:計画の量を「半分」にするところから始める

最初に立てた計画は、多くの場合、実行可能な量の2倍近くになっています。

- **NG:** 「そんなにたくさん無理でしょ。どうせ続かないよ」
- **OK:** 「いい計画だね。まず、いちばん大事なものだけ残すとしたら何かな?」

**ポイントは、否定ではなく「絞る」ことを一緒に考えることです。** 学ジムが大切にしている「継続の負荷設定」も、まず続けられる軽さから始める考え方です。

### ステップ2:「何時間やる」ではなく「何をやる」で決める

時間で区切る計画は、座っているだけでも達成できてしまい、手応えが残りません。

- **NG:** 「今日は3時間ちゃんと座ってなさい」
- **OK:** 「今日はワーク2ページと英単語20個。終わったらおしまいにしよう」

終わりが見える計画は、お子さんの「やりきった」という感覚を育てます。

### ステップ3:「いつ・どこで」まで決める

計画に、実行のきっかけを書き込みます。

- **NG:** 「時間があるときにやればいいよ」
- **OK:** 「夕食のあと、リビングのテーブルで15分。ここまで決めておこうか」

「時間があるとき」は、永遠に来ません。**きっかけを具体的にすることが、続く計画の土台**です。

### ステップ4:予備日をあらかじめ入れておく

予定通りに進まない日は、必ず来ます。週に1日は「予備日」として空けておきましょう。

- **NG:** 「昨日できなかった分、今日2倍やりなさい」
- **OK:** 「昨日の分は予備日に回そう。今日は今日の分だけで大丈夫」

遅れを一気に取り返させようとすると、次の挫折につながります。

### ステップ5:週に1回、「責めない振り返り」をする

週末に5分だけ、計画と実際を一緒に見る時間をつくります。ここでの問いは「なぜできなかったの?」ではなく、「どうしたらやりやすくなる?」です。

- **NG:** 「ほら、やっぱりできてないじゃない」
- **OK:** 「ここまでは進んだね。来週は何を変えたらやりやすそう?」

**振り返りの目的は、反省ではなく、計画の改良です。**

| 計画が3日で止まった | 「また三日坊主ね」 | 「3日続いたのはすごいね。続けやすくするには何を変えようか」 |
| 計画が詰め込みすぎ | 「無理に決まってるでしょ」 | 「どれが一番大事? まずそこから残そう」 |
| 予定をこなせなかった | 「なんでやらなかったの」 | 「どこでつまずいた? 一緒に見てみよう」 |
| 遅れを取り戻したい | 「今日2日分やりなさい」 | 「予備日に回そう。今日の分だけでいいよ」 |
| 計画表を見せてくれた | 「どうせ守らないんでしょ」 | 「自分で立てたんだね。まず1日やってみよう」 |
| 少しでも進んだ | 「まだ半分じゃない」 | 「ここまで進んだね。続いているのがいいところだよ」 |
| 勉強を始めない | 「早く始めなさい」 | 「夕食のあと、まず10分だけ始めてみようか」 |

**声かけは、一度に全部変えようとしなくて大丈夫です。** まずは一つだけ、今日から選んで試してみてください。

## まとめ

計画が続かないお子さんの多くは、やる気がないのではなく、**「続く計画の作り方」と「崩れたときの立て直し方」をまだ知らないだけ**です。保護者様の役割は、計画を管理することでも、守らせることでもありません。**お子さんが「崩れても、直せばいい」と思える安心感を届けること**です。

計画を立てても続かない姿を見るのは、保護者様にとってもつらいことだと思います。つい強い言葉が出てしまうのも、お子さんを思うがゆえです。どうかご自身を責めないでください。今日の夜、たった一つの声かけを変えてみる。それだけで、ご家庭の空気は少しずつ変わっていきます。
