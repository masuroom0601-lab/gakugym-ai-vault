# 総合型選抜、親はどこまで手伝っていい? ― 志望理由書と向き合う保護者様へ

## 導入

お子さまが総合型選抜(旧AO入試)に挑戦すると決めたとき、保護者様の頭にはこんな迷いが浮かんでいませんか。

志望理由書の下書きを見せてもらったら、正直「これで大丈夫だろうか」と不安になった。かといって、手を貸しすぎたら子ども本人の言葉ではなくなってしまう気がする。逆に何も言わずに任せていたら、提出期限が迫っているのに一向に進んでいない——。「手伝うべきか、見守るべきか」の間で揺れ動く保護者様のお悩みを、私はこの時期になると本当によくお聞きします。

**総合型選抜で一番難しいのは、勉強を教えることよりも「どこまで手を出すか」の線引きです。** 今日は、この境界線をどう考えればいいのか、心理学や教育コーチングの知見も交えながらお話しします。

## 理論的背景:なぜ「手伝いすぎ」は逆効果になるのか

発達心理学に「足場かけ(スキャフォールディング)」という考え方があります。子どもが一人ではまだ届かない課題に取り組むとき、大人が手を添えて支え、**できるようになった部分から少しずつ手を離していく**という支援のあり方です。ここで大切なのは、足場はあくまで「一時的な支え」であり、最終的には外れることが前提だという点です。

総合型選抜の志望理由書は、まさにこの足場かけが必要な場面です。文章の型や構成の考え方は保護者様が示してあげてもいい。しかし、**「なぜその大学で学びたいのか」という中身そのものは、子ども自身が何度も考え直しながら見つけていくものです。** ここを保護者様が代わりに埋めてしまうと、足場が外れないまま完成した文章になってしまいます。

自己決定理論の観点からも、同じことが言えます。人が本気で取り組めるのは、**自分の言葉・自分の考えだと感じられるとき**です。志望理由書を面接で問われたときに、自分の言葉でないと答えに詰まってしまう——これは、内容の良し悪し以前に、その子が「自分ごと」として語れるかどうかの問題です。保護者様が完成させた文章は、たとえ表現が上手でも、本人にとっては「借り物の言葉」になりがちです。

もうひとつ知っておいていただきたいのが、**「手伝う」と「介入する」は別物だ**という視点です。コーチングの世界では、相手の考えを引き出す問いかけを「支援」、相手の答えを先回りして与えてしまうことを「介入」と区別します。保護者様の役割は、答えを渡すことではなく、**子ども自身がまだ言葉にできていない考えを、問いかけによって引き出す**ことにあります。

## 具体的な実践ステップ

理論を踏まえて、志望理由書づくりの場面で今日から意識できる4つのステップをご紹介します。

### ステップ1:文章ではなく「問い」を渡す

下書きを読んで直したい部分が見えても、いきなり赤字を入れるのではなく、まず問いかけてみましょう。

- **NG例**:「ここはこう書いたほうがいいよ」と文章を書き直して渡す
- **OK例**:「ここでいちばん伝えたいことは、一言でいうと何?」

**問いに答えようとする過程そのものが、本人の考えを深める時間になります。** 答えを渡してしまうと、その一往復だけで終わってしまいます。

### ステップ2:「完成度」より「本人の言葉かどうか」を確認する

読みやすさや文法の美しさに目が行きがちですが、まず見るべきはそこではありません。

- **NG例**:「この表現、もっと大人っぽく直そうか」
- **OK例**:「これ、面接で聞かれても自分の言葉で説明できそう?」

多少ぎこちない文章でも、**本人の実感がこもった言葉のほうが、最終的に強い文章になります。** 面接まで見据えると、この視点はとても重要です。

### ステップ3:「手伝ってほしい範囲」を先に本人に聞く

保護者様の善意で手を出す前に、どこまで手伝ってほしいのかを子ども自身に確認しておくと、あとの摩擦がぐっと減ります。

- **NG例**:相談されていないのに、構成ごと直してしまう
- **OK例**:「誤字だけチェックしてほしい? それとも内容の相談にも乗ってほしい?」

**手伝う範囲を本人が決められることが、そのまま「自分の受験」だという実感につながります。** 保護者様は伴走者であって、共著者ではありません。

### ステップ4:進んでいない時こそ、責めずに状況を聞く

提出期限が近づいているのに手が止まっていると、つい焦りから強い言葉が出てしまいます。ですが、止まっているのには必ず理由があります。

- **NG例**:「まだ書けてないの? 期限過ぎちゃうよ」
- **OK例**:「今、どのあたりで止まってる? 一緒に整理してみようか」

**止まっている理由が分かれば、手伝い方も自然と見えてきます。** 責める言葉は、次の一歩をさらに遠ざけてしまいます。

## フレーズ変換集

志望理由書づくりの場面でとっさに出てしまいがちな言葉を、意識して変換するだけで、子どもとの向き合い方は大きく変わります。ぜひ使ってみてください。

| よく言ってしまう言葉(NG) | 変換後のひとこと(OK) |
| --- | --- |
| ここはこう書いたほうがいいよ | ここでいちばん伝えたいことは何? |
| もっと大人っぽい表現にしようか | これ、自分の言葉で説明できそう? |
| まだ書けてないの? | 今、どのあたりで止まってる? |
| 私が直しておくね | どこまで手伝ってほしい? |
| 他の子はもう終わってるらしいよ | 今のペースで、次は何をする予定? |
| これじゃ通らないと思うよ | ここまでよく考えられてるね、続きも聞かせて |

**共通しているのは、「答えを渡す」のではなく「問いを渡す」形にしているという点です。** すべてを変える必要はありません。次に下書きを見せてもらう場面で、ひとつ試してみてください。

## まとめ

総合型選抜の準備は、保護者様にとっても初めての経験であることが多く、正解が見えにくいものです。それでも、**手を貸すべき場面と、あえて手を離すべき場面を意識するだけで、子どもの文章にも表情にも変化が表れます。**

大切なのは、完璧な志望理由書を仕上げることではなく、子ども自身が「これは自分で考えて、自分で決めた」と思えることです。それは、合否の結果以上に、この先の学びに向かう姿勢を支える土台になります。

私たち学ジムでも、総合型選抜に挑む生徒たちの伴走を大切にしています。**勉強を、筋トレのように"続けられる仕組み"に変える**——そのために、コーチが問いかけを重ねながら本人の考えを引き出し、無理のない「継続の負荷設定」で提出までの日々を一緒に整理しています。ご家庭だけで抱え込まず、隣で問いを投げかけてくれる相手がいるだけでも、志望理由書と向き合う時間は変わるものです。

今日ご紹介した向き合い方を、ぜひ一つからで大丈夫ですので、試してみてください。保護者様とお子さまにとって、志望理由書づくりの日々が、少しでも前向きなものになりますように。
