# テストが返ってきた日の夜、点数を見て叱ってしまいそうな時に ― 問題は「叱り方」ではなく「叱る前の数秒」です

## 導入

定期テストが返却された日の夜。お子さんが差し出した答案を見て、こんな気持ちになったことはないでしょうか。

- 想像より低い点数に、頭が真っ白になった
- 「なんでこんな問題を間違えるの!」と、気づいたら口に出ていた
- 叱ったあと、お子さんが黙って部屋に行ってしまい、後悔した

保護者様が点数に反応してしまうのは、お子さんの将来を真剣に考えているからです。私も、答案を前に「また感情的に言ってしまいました」と落ち込まれる保護者様に、何度もお会いしてきました。決して、保護者様が冷たいわけでも、未熟なわけでもありません。

先に結論をお伝えします。**点数を見た直後の一言は、その後のお子さんの学習意欲を大きく左右します。** そして変えるべきは叱り方のテクニックではなく、**「答案を見てから口を開くまでの数秒の使い方」**です。この記事では、その数秒の過ごし方と、返却日の夜の会話の進め方を、NG/OKの例つきでお伝えします。

## 理論的背景:なぜ点数で叱ると、成績が伸びにくくなるのか

### 人は「責められる」と、原因を考える力が落ちます

強い叱責を受けると、人は脅威を感じて防衛モードに入り、「どうすれば良くなるか」を考える余裕を失いやすくなります。**叱られたお子さんの頭の中は、「反省」ではなく「この場をどうやり過ごすか」でいっぱいになっている**ことが少なくありません。

### 「結果」ではなく「原因」に目を向けると、次の行動が変わる

心理学の達成動機づけの研究(帰属理論)では、失敗の原因を「才能がない」「頭が悪い」といった変えられないものに求めると意欲が下がり、「やり方」「準備の量」といった変えられるものに求めると、次の行動につながりやすいとされています。**点数を責める声かけは「才能の問題」に、やり方を一緒に見る声かけは「やり方の問題」にお子さんの意識を向けます。**

### コーチングでは「評価」の前に「承認」を置きます

コーチングの基本は、答えを教えることではなく、本人の中にある答えを引き出すことです。そのためにまず必要なのが、結果の良し悪しではなく**「テストに向き合った事実」を承認すること**。承認されて初めて、お子さんは自分から失敗を振り返れるようになります。

## 実践ステップ:返却日の夜の進め方

### ステップ1:答案を見たら、まず6秒、何も言わない

怒りのピークは数秒で下がると言われています。**口を開く前に、ゆっくり深呼吸を一つ。** 「見せてくれてありがとう」と心の中で唱えるだけでも十分です。

- **NG:** 答案を見た瞬間に「なにこの点数!」
- **OK:** 一呼吸おいてから「見せてくれてありがとう」

そもそも、点数の悪い答案を自分から見せてくれたこと自体が、お子さんからの信頼のサインです。

### ステップ2:最初の一言は、点数ではなく「事実への承認」

- **NG:** 「で、今回は何点だったの? 前回より下がってるじゃない」
- **OK:** 「テスト、お疲れさま。結果を見せてくれてありがとう」

**点数の話は、その後で構いません。** 最初に「味方である」ことを伝えると、お子さんの防衛モードが解けます。

### ステップ3:点数ではなく「どこで失点したか」を一緒に見る

- **NG:** 「なんでこんな簡単な問題を間違えるの!」
- **OK:** 「どの問題が悔しかった? 一緒に見てみようか」

**失点を「知識不足」「ケアレスミス」「時間切れ」に分けて見る**と、感情の話が作業の話に変わります。原因が分かれば、次に何をすればいいかも見えてきます。

### ステップ4:良かった点を一つ、具体的に探す

- **NG:** 「ここは当たり前でしょ。できてない所が問題なの」
- **OK:** 「この大問は、前回より正解が増えているね。ここは勉強の成果が出てるよ」

**平均点や順位より、「本人の前回との差」を見る**のがポイントです。小さな伸びを言葉にすることが、次の学習の燃料になります。

### ステップ5:「次の一手」はお子さんに選んでもらう

- **NG:** 「次からは毎日2時間やりなさい」
- **OK:** 「次のテストに向けて、まず何から変えてみたい?」

保護者様が計画を決めてしまうと、お子さんは「やらされる側」になります。**自分で選んだ一手は、続く確率が上がります。** 「ポイントで見える化する自習」のように、小さく、測れる形にすると続けやすくなります。

### ステップ6:どうしても感情が溢れそうな時の「撤退ルール」

- **NG:** 感情が高ぶったまま話し続ける
- **OK:** 「ごめん、今ちょっと驚いてるから、10分あとで一緒に見させて」

**一度席を外すのは、逃げではなく、お子さんを守る行動です。** 感情的に叱ってしまった時も、「さっきは言いすぎたね」と翌日に一言添えれば、関係は十分に修復できます。

## フレーズ変換集

返却日の場面別の言い換えです。スマホのメモに保存して、とっさのときにお使いください。

| 場面 | NGフレーズ | OKフレーズ |
|---|---|---|
| 答案を渡された瞬間 | 「うわ、何この点数」 | 「見せてくれてありがとう」 |
| 点数が下がっていた | 「だから言ったでしょ」 | 「思ったより取れなくて悔しいよね。どこが一番悔しい?」 |
| ケアレスミスが多い | 「ちゃんと見直さないからでしょ」 | 「見直しの時間、足りなかった? どうしたら間に合いそう?」 |
| 友達や兄弟と比べたくなる | 「○○ちゃんは取れてるのに」 | 「前回の自分と比べて、どこが変わったかな」 |
| 勉強量が気になる | 「もっとやらないとダメでしょ」 | 「次は何から変えてみたい? 手伝えることはある?」 |
| 本人が落ち込んでいる | 「落ち込む前にやることがあるでしょ」 | 「しんどいよね。まず今日はゆっくりしよう。続きは明日見ようか」 |
| つい叱ってしまった後 | (何も言わずに気まずくなる) | 「昨日は言いすぎたね。ごめん。もう一度一緒に見てもいい?」 |

**全部を変えようとしなくて大丈夫です。** まずは「なんでこんな点数なの」を、「見せてくれてありがとう」に変えることだけ、試してみてください。

## まとめ

答案を前に感情が揺れるのは、お子さんを大切に思っているからこそです。叱ってしまった日があっても、それで親子の関係が壊れることはありません。**大切なのは、完璧に対応することではなく、次の返却日に「あの数秒」を一度だけ思い出すことです。**

点数は、今回の結果を表す一つの数字にすぎません。その先にある「次はどうするか」を、お子さんと一緒に考えられる関係こそが、長い目で見て成績を支えます。どうか保護者様ご自身も、自分を責めすぎず、お子さんの味方でいてあげてください。

オープンチャットにて学部研究シートも配布しております。お子様の志望校選びや総合型対策に是非お役立てください!

学ジムでは、勉強を「続けられる仕組み」に変えるお手伝いをしています。ご家庭での声かけや、テスト後の振り返りの進め方に迷われたときは、お気軽にご相談ください。
