# 「勉強しなさい」と言うほど、子どもは机に向かわなくなる ― 保護者様に知ってほしい声かけの工夫

## 導入

保護者様、今日も「勉強しなさい」と声をかけて、ため息をついていませんか。

帰宅した子どもがスマホばかり触っている。宿題を後回しにする。声をかけるたびに「今やろうと思ってた」と不機嫌になる。分かっていても、つい強い言葉が出てしまう自分にも疲れてしまう——そんな保護者様の声を、私は本当にたくさん聞いてきました。

**「勉強しなさい」は、言えば言うほど効かなくなる言葉です。** それどころか、親子関係そのものをすり減らしてしまうことすらあります。でもそれは、保護者様の伝え方が悪いからではありません。声かけの「仕組み」を少し変えるだけで、子どもの反応は驚くほど変わります。今日は、その仕組みについてお話しします。

## 理論的背景:なぜ「勉強しなさい」は逆効果になるのか

心理学に「自己決定理論」という考え方があります。人が本気で行動を続けられるのは、**誰かにやらされているときではなく、「自分で決めた」と感じているとき**だという理論です。ここでは3つの感覚が鍵になります。

- **自律性**:自分の意思で選んでいると感じられること
- **有能感**:やればできると感じられること
- **関係性**:見守ってくれる相手がいると感じられること

「勉強しなさい」という言葉は、この3つのうち「自律性」を真っ向から奪います。子どもの頭の中では「勉強したい」ではなく「言われたからやる/やらない」というスイッチに切り替わってしまうのです。これは反抗期に限らず、どの年齢の子どもにも起こる、ごく自然な心理反応です。

コーチングの世界でも同じことが言われています。人を動かすのは「指示」ではなく「承認」です。結果だけを見て評価するのではなく、**取り組んでいる過程そのものを認めてもらえた**とき、人は次の一歩を自分から踏み出せます。これは私が生徒と接する中でも、日々実感していることです。

そしてもうひとつ大切なのが、小さな成功体験の積み重ねです。行動科学では、努力してもすぐに結果が見えないと、人はその行動をやめてしまうとされています。裏を返せば、**小さな達成を本人が「見える形」で確認できれば、行動は続きやすくなる**ということです。

## 具体的な実践ステップ

理論だけでは、明日から何をすればいいか分かりにくいですよね。ここからは、家庭で今日から試せる4つのステップをご紹介します。

### ステップ1:声をかけるタイミングを変える

帰宅直後や食事の最中は、子どもにとって一番気が緩んでいる時間です。そこに「勉強は?」という言葉が飛んでくると、リラックスできる場所がなくなってしまいます。

- **NG例**:「ただいま」と同時に「宿題やったの?」
- **OK例**:一息ついた頃を見計らって「今日は何時から始める?」

問いかけを「命令」から「相談」に変えるだけで、子どもは自分で決めたという感覚を持てます。

### ステップ2:結果より過程を言葉にする

点数やテスト結果だけを評価すると、子どもは「結果が出ないなら報告したくない」という気持ちになります。

- **NG例**:「この前より点数下がったね」
- **OK例**:「毎日机に向かってたの、ちゃんと見てたよ」

**過程を認められた経験がある子どもほど、次も挑戦しようとします。** これは私が指導現場で何度も見てきた変化です。

### ステップ3:小さな目標を「見える化」する

やる気は気分に左右されますが、記録は裏切りません。その日やったページ数や時間を、カレンダーやノートに書き出すだけで、努力が「ポイントで見える化する自習」に変わります。

- **NG例**:「今日はどのくらい頑張ったの?」と口頭だけで確認する
- **OK例**:一緒に一週間分の記録表を作り、埋まっていく様子を眺める

数字や印として積み上がっていく様子は、子ども自身にとっても大きな自信になります。

### ステップ4:「教える」より「聞く」

つまずいている様子を見ると、つい保護者様のほうが答えを教えたくなります。ですが、まず聞くことが先です。

- **NG例**:「それはこうやるんだよ」とすぐに解き方を説明する
- **OK例**:「どこまで自分で考えた?」「どこで止まった?」と聞いてみる

子どもが自分の言葉で状況を説明する過程そのものが、思考の整理につながります。

## フレーズ変換集

とっさに出てしまいがちな言葉を、意識して変換するだけで印象は大きく変わります。日常のワンシーンで、ぜひ使ってみてください。

| よく言ってしまう言葉(NG) | 変換後のひとこと(OK) |
| --- | --- |
| 早く宿題やりなさい | 宿題、何時からやる予定? |
| なんでできないの? | どこまでは分かった? |
| また同じ間違いしてる | 前より気づくの早くなったね |
| スマホばっかり見て | 休憩、あとどのくらいにする? |
| もっと頑張りなさい | 今日はここまでやったんだね |
| 勉強しないと将来困るよ | 今のうちに続ける力をつけておこうか |

**共通しているのは、「評価」ではなく「対話」の形にしているという点です。** 一気にすべてを変える必要はありません。まずはひとつ、口ぐせにしてみてください。

## まとめ

子育ての悩みに、簡単な正解はありません。それでも、声のかけ方ひとつで、子どもとの関係も、机に向かう姿勢も、少しずつ変わっていきます。

**「勉強しなさい」をやめることは、甘やかすことではありません。** 子ども自身が「自分で決めて、続けられた」という感覚を積み重ねられるように、隣で支える伴走の仕方を変えるということです。

私たち学ジムでも、この考え方を大切にしています。**勉強を、筋トレのように"続けられる仕組み"に変える**——そのために、無理のない「継続の負荷設定」をコーチと一緒に作り、努力をポイントで見える化しながら伴走しています。ご家庭だけで抱え込まず、頼れる相手がもうひとり増えるだけでも、子どもの表情は変わるものです。

今日ご紹介した声かけを、ぜひ一つからで大丈夫ですので、試してみてください。保護者様と子どもの毎日が、少しでも穏やかなものになりますように。
