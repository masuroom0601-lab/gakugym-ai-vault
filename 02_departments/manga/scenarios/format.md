# シナリオの書式(2026-11-22、益田さん指定)

すべての話のシナリオは、この書式で書く。

| 要素 | 書き方 | 例 |
|---|---|---|
| ページ | `≪pageN≫`(漫画内でのページ数) | ≪page4≫ |
| 柱 | 行頭に `〇`。場所・時間・状況を書く。回想の出入りや場面転換も柱で示す | 〇グラスト王国の城内 主人公が王の間で国王と謁見 |
| ト書き | 記号なしの地の文。登場人物の動き・表情・状況を書く | 王に突如呼び出され何事かと思っていたら、無能として追放を宣告される |
| セリフ | `名前「〜」` | 王「グラ男、無能のお前は辺境に追放だ」 |
| モノローグ | `名前(〜)` | グラ男(俺は確かに攻撃系の魔法は使えないが……) |

## 補足ルール
- 回想は「〇回想に突入 〜」で入り、「〇回想終了」で出る
- 場面が変わるときは「〇場面転換 〜」と書く
- 同じ場所が続くときは「〇〜(続き)」と書く
- 囲み文字・ナレーション・効果音・ステータス表示は、ト書きの中に書くか、
  `ナレーション「〜」` `ステータス表示「〜」` のようにセリフと同じ形で書く

## 参考にした例(益田さん提供)
```
≪page4≫
〇グラスト王国の城内 主人公が王の間で国王と謁見
戦場で負傷した戦士達の治療にあたっていたグラ男
王に突如呼び出され何事かと思っていたら、王に無能として追放を宣告される
王「グラ男、無能のお前は辺境に追放だ」
グラ男「な…! 何故です!?」
グラ男(俺は確かに攻撃系の魔法は使えないが、唯一使える治癒魔法で精一杯国に貢献できるよう頑張ってきたつもりだ)
〇回想に突入 グラ男が過去を思い出す
```

## トーンのルール(2026-11-22、益田さん指定)
- オタク受けは今回は狙わない。恋愛やドキッとする場面は、一般の大学生が読んで
  自然に感じる範囲で描く
- 恋愛経験の少なさをネタにするような、いわゆる“童貞ネタ”のモノローグは使わない

## スキルの扱い(2026-11-22、益田さん指定)
- スキル(【無限想像】【無限創造】)とステータス表示は、追放ものの“ファンタジーのテンプレ”から
  外れすぎないための演出。**表示するだけで、特別な能力としての意味は持たせない**
- 「スキルが発動する」「作り方まで全部見える」のような、スキルを超能力として描く表現は使わない。
  イヅルのアイデアは、イヅル自身が考えて生み出したものとして描く
- **登場人物はスキルに一切触れない**(2026-11-22追加)。セリフやモノローグでスキル名を口にしたり、
  ステータス表示に反応したりしない。スキルやステータスは、作中に文字で表示するだけ

## ラブコメ要素の扱い(2026-11-22、益田さん指定)
- この漫画の主目的は、学生団体CAPSの紹介。ラブコメ要素はあくまでおまけで、控えめにする
- 作中で告白はしない。椎菜もイヅルも「好き」と自覚する描写はしない
- 二人の関係は「信頼し合う仲間」が基本。ドキッとする場面は、1話に1回程度の軽いものにとどめる

## 入れない要素(2026-11-22)
- 学内コンペ(表彰・優勝・順位など)の要素は、作品全体で一切入れない
- 「この大学では誰もがスキルを持っている」といった世界観の説明は、ナレーションでも明示しない(2026-11-22)

## ギャグと悪役の扱い(2026-11-22、益田さん指定)
- ギャグは今作品では極力抑える。しゃべるセーター・土鍋・埴輪は“そういう存在”として自然に描き、
  驚きのギャグ顔・ドタバタ・ツッコミの掛け合いなどは入れない
- 勇者サークルの4人(リュウセイを含む)は全員、悪役として描く。リュウセイだけを“いい人”や“正直者”に見せない

## セーターの描き方(2026-11-23 変更)
- セーターは、胸に顔がある喋るセーター。**だれにも着られておらず、服だけで登場する**(鍋さん・ハニワ君と同じ“そういう存在”)
- ふだんはイスの背もたれやハンガーにかかっている。袖を少し動かすことはできるが、歩いたり物を持ったりはしない
- 移動するときや、物を書く・掲げるなどの動きは、ほかのメンバー(主にD助)がハンガーごと運んだり、代わりにやったりする
- D助はサングラスの男子メンバー(司会担当)。セーターを着ていない

## 鍋さん・ハニワ君の描き方(2026-11-22、2026-11-23 追記)
- 鍋さんは土鍋で、**フタの下に目と口がある**(顔のある土鍋)。手はない。フタを鳴らす・湯気を立てる・しゃべることはできるが、物を配ったり差し出したりはしない
  (おでんを配る場面は、ほかのメンバーが取り分ける)
- おでんは絵として登場させてよいが、**セリフではおでんに触れない**(2026-11-24、益田さん指定)
- ハニワ君は埴輪で、指のない短い腕がある。うなずく・腕を上げる・手ぶりはできるが、「親指を立てる」など指の動きはしない
- ハニワ君は口数が少ないが、無言ではない。短い言葉なら話す(例:「……ようこそ」)

## 椎菜の名前と口調(2026-11-23、益田さん指定)
- キャラ名は「椎菜」(名字の「片倉」は使わない)。初登場時(第1話の自己紹介)にルビを振る: 椎菜《しいな》
- ルビの書き方: 漢字のあとに《ひらがな》を付ける(原稿では、文字の右側に小さく表示する)
- 椎菜は敬語を使わず、だれに対してもため口で話す(勇者サークルの先輩に対しても)
- 椎菜の髪は、白に近い明るい色のロングヘアに黒いリボン。**どのコマでも同じ色にそろえる**。八重歯はなし(2026-11-23)

- 益田さんが共有した参考画像は、方向性の参考にとどめる(画像はリポジトリに保存しない)

## 勇者サークルの4人の名前(2026-11-23 変更)
- シロ(部長・勇者)、アイミ(広報・魔法使い/旧イッシ)、リュウセイ(会計・術士/旧ヤス)、タマキ(副部長・聖女/旧つぶ)

## 第1話の救出場面でのスキルの見せ方(2026-11-23、益田さん指定)
- イヅルが一瞬のうちに、いくつもの方法を思い浮かべて比べる様子を、小さなコマの連続で見せる
  (殴りかかる/先生を呼ぶ/大声を出す/スマホで撮る……)。そこに【無限想像】の文字表示を重ねる
- 思い浮かべるのはイヅル自身の頭の中で、超能力としては描かない。登場人物がスキル名を口にしない点は、ほかの話と同じ

## 勇者サークルの設定(2026-11-24、益田さんと決定。これが最新)
- 勇者サークルは大学の一サークル。活動内容は、キャンパスの北の外れにある「北の迷宮」で、魔王討伐を目指して冒険すること
  (魔王は、迷宮の最深部にいるとされる存在)。通称「勇者サークル」
- 冒険は大学公認の課外活動。迷宮に入るには、大学の事務(学生課)への**冒険許可書の申請**が必要。どの層まで踏破したかは、大学の冒険記録に残る
- 冒険の実績は就活で強いため、「就職に強いサークル」として人気が高い
- ファンタジーの要素は最小限にする。授業・SNS・就活など、それ以外の大学生活は現実と同じ
- 役割: シロ=部長・勇者(剣)、アイミ=広報・魔法使い、リュウセイ=会計・術士、タマキ=副部長・聖女(回復役)
- イヅルは戦闘未経験。陰で、地図づくり・ルートの下調べ・補給(食料・ポーション)の準備・魔物や罠の情報集め・
  冒険許可書の申請・冒険の様子のSNS発信(広報の実務)・企画の案出しを、全部一人でやっていた。手柄は全部シロたちのものになっていた
- 勇者サークルが落ちぶれていく様子は、新歓の企画ではなく、冒険の途中の失敗で描く(道に迷う・補給切れ・罠・許可書の不備など)
- 第1話の決定事項の「魔王討伐=最強のガクチカ作りの意味」は、この設定に置きかえる(魔王討伐の冒険は実際にあり、その実績がガクチカになる)

## テーマとステータス表示・呼び方(2026-11-24、益田さん指定)
- 作品のテーマの言葉は「**あなたの“想像”を形にする**」(CAPSは、あなたの“想像”を形にするサークル)。
  旧案の「あなたの“これやりたい”を叶える」は使わない。最終話の締めは「あなたの“想像”を、CAPSで形にしよう」
- 努力値のゲージのステータス表示(「スキル【無限想像】 努力値:▮▮▮▯▯……」など)は**一切廃止**。
  残すのは、第4話4ページの「努力値が一定量を超えました」「スキル【無限想像】が、エクストラスキル【無限創造】に進化しました」だけ
  (作画済みの第1話33ページ・第2話18ページからも消した。第1話のスキル名の表示「スキル:【無限想像】」(2ページ・13ページ)も消した)
- (2026-11-25 変更)第4話の進化の表示が唐突になるため、第1話13ページ(救出の方法を思いつく目のコマ)にだけ「スキル:【無限想像】」の表示を戻す。
  作中のステータス表示は、第1話13ページと第4話4ページの2か所のみ(第1話の扉の、学生たちのガクチカの表示は別扱い)
- (2026-11-25)時期: 第1〜3話は春。第4話のダイジェストで数か月たち(夏休みの理科実験教室・フェス)、第5話はフェスの打ち上げ(秋)、第6〜7話はそのあと
- イヅルは椎菜を「椎菜」と呼び、ため口で話す(「椎菜さん」は使わない)。椎菜とイヅルは同学年・同い年(2年生)
- CAPSは、インカレ(複数の大学の学生が集まる)の学生団体
