# シナリオの書式(2026-11-22、益田さん指定)

すべての話のシナリオは、この書式で書く。

| 要素 | 書き方 | 例 |
|---|---|---|
| ページ | `≪pageN≫`(漫画内でのページ数) | ≪page4≫ |
| 柱 | 行頭に `〇`。場所・時間・状況を書く。回想の出入りや場面転換も柱で示す | 〇グラスト王国の城内 主人公が王の間で国王と謁見 |
| ト書き | 記号なしの地の文。登場人物の動き・表情・状況を書く | 王に突如呼び出され何事かと思っていたら、無能として追放を宣告される |
| セリフ | `名前「〜」` | 王「グラ男、無能のお前は辺境に追放だ」 |
| モノローグ | `名前(〜)` | グラ男(俺は確かに攻撃系の魔法は使えないが……) |

## 補足ルール
- 回想は「〇回想に突入 〜」で入り、「〇回想終了」で出る
- 場面が変わるときは「〇場面転換 〜」と書く
- 同じ場所が続くときは「〇〜(続き)」と書く
- 囲み文字・ナレーション・効果音・ステータス表示は、ト書きの中に書くか、
  `ナレーション「〜」` `ステータス表示「〜」` のようにセリフと同じ形で書く

## 参考にした例(益田さん提供)
```
≪page4≫
〇グラスト王国の城内 主人公が王の間で国王と謁見
戦場で負傷した戦士達の治療にあたっていたグラ男
王に突如呼び出され何事かと思っていたら、王に無能として追放を宣告される
王「グラ男、無能のお前は辺境に追放だ」
グラ男「な…! 何故です!?」
グラ男(俺は確かに攻撃系の魔法は使えないが、唯一使える治癒魔法で精一杯国に貢献できるよう頑張ってきたつもりだ)
〇回想に突入 グラ男が過去を思い出す
```

## トーンのルール(2026-11-22、益田さん指定)
- オタク受けは今回は狙わない。恋愛やドキッとする場面は、一般の大学生が読んで
  自然に感じる範囲で描く
- 恋愛経験の少なさをネタにするような、いわゆる“童貞ネタ”のモノローグは使わない

## スキルの扱い(2026-11-22、益田さん指定)
- スキル(【無限想像】【無限創造】)とステータス表示は、追放ものの“ファンタジーのテンプレ”から
  外れすぎないための演出。**表示するだけで、特別な能力としての意味は持たせない**
- 「スキルが発動する」「作り方まで全部見える」のような、スキルを超能力として描く表現は使わない。
  イヅルのアイデアは、イヅル自身が考えて生み出したものとして描く
- **登場人物はスキルに一切触れない**(2026-11-22追加)。セリフやモノローグでスキル名を口にしたり、
  ステータス表示に反応したりしない。スキルやステータスは、作中に文字で表示するだけ

## ラブコメ要素の扱い(2026-11-22、益田さん指定)
- この漫画の主目的は、学生団体CAPSの紹介。ラブコメ要素はあくまでおまけで、控えめにする
- 作中で告白はしない。椎菜もイヅルも「好き」と自覚する描写はしない
- 二人の関係は「信頼し合う仲間」が基本。ドキッとする場面は、1話に1回程度の軽いものにとどめる

## 入れない要素(2026-11-22)
- 学内コンペ(表彰・優勝・順位など)の要素は、作品全体で一切入れない
- 「この大学では誰もがスキルを持っている」といった世界観の説明は、ナレーションでも明示しない(2026-11-22)

## ギャグと悪役の扱い(2026-11-22、益田さん指定)
- ギャグは今作品では極力抑える。しゃべるセーター・土鍋・埴輪は“そういう存在”として自然に描き、
  驚きのギャグ顔・ドタバタ・ツッコミの掛け合いなどは入れない
- 勇者サークルの4人(ヤスを含む)は全員、悪役として描く。ヤスだけを“いい人”や“正直者”に見せない

## セーターの描き方(2026-11-22)
- セーターはD助が着ている服で、胸に顔がある。セーター自身は歩いたり、物を持ったりできない
- セーターの動き(立つ・進み出る・書く・掲げるなど)は、ト書きで「D助が〜し、胸のセーターが〜」と書く

## 鍋さん・ハニワ君の描き方(2026-11-22)
- 鍋さんは土鍋で、手がない。フタを鳴らす・湯気を立てる・しゃべることはできるが、物を配ったり差し出したりはしない
  (おでんを配る場面は、ほかのメンバーが取り分ける)
- ハニワ君は埴輪で、指のない短い腕がある。うなずく・腕を上げる・手ぶりはできるが、「親指を立てる」など指の動きはしない
