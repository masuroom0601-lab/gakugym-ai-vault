## ミッション
AIが描く漫画を、できるだけ「人間が描いたような」作風で制作する。
作品の中身(ジャンル・テーマ・用途)は益田さんの指示で決める。

## 基本方針
- **完全無料で作る**。Claude Code Proの契約の範囲内で完結させ、有料の画像生成サービス
  (Higgsfield等)や有料素材は使わない。
- **描くのはAI**。益田さんの作業は、方向性の指示・参考イラストの提供・最終確認に限る。
- **公開前には必ず益田さんが確認する**(全部署共通ルール)。

## 制作方式
益田さんのPCはIntel UHD Graphics(独立GPUなし)のため、画像生成AIはローカルで動かせない。
代わりに、Claude Code on the webのクラウド環境でBlender(PyPIの`bpy`)を動かし、
Claudeがプログラムで直接操作して描く。MCP連携やプラグインは不要。
(2026-11-21、クラウド環境で`bpy` 5.3による描画が約5秒/枚で動くことを確認済み)

1. **シナリオ・ネーム**: Claudeが話・コマ割り・構図・セリフを作る(`scenarios/`)
2. **キャラクター**: 益田さんの参考イラスト(`references/`)に合わせて、Claudeが
   Blender上で簡単な人型から作る(`characters/`)
3. **作画**: ポーズ・カメラ・背景をBlenderで組み、線画(Freestyle)とトーンで描き出す
4. **仕上げ**: 線の揺らぎ・強弱、効果線、トーン、吹き出し、写植をPythonの画像処理で入れる
5. **確認**: `drafts/` → 益田さん確認 → `review/` → 承認後 `published/`

## 「人間らしい作風」のための工夫
- 輪郭線を均一にせず、揺らぎと強弱、途切れを入れる
- 陰影はグラデーションにせず、少ない階調のトーンに分ける
- 3Dっぽい完璧なパースや左右対称を避け、少し崩す
- 写植には手書き風の無料フォントを使う

## フォルダ構成
- `references/`: 益田さんから受け取った参考イラスト(作風・キャラの見本)
- `characters/`: キャラクター設定(設定画・Blenderモデル・作成スクリプト)
- `scenarios/`: シナリオ・ネーム
- `drafts/` / `review/` / `published/`: 原稿の確認段階ごとの置き場
- `tools/`: 制作用スクリプト
  - `setup.sh`: 作業環境の準備(セッションの最初に実行)
  - `render_check.py`: 描画の動作確認

## 注意事項
- 参考イラストは「作風・雰囲気の見本」として使う。既存の作品やキャラクターを
  そのまま再現・模写した原稿は作らない。
- クラウド環境は一時的なため、成果物は必ずこのリポジトリにコミットして残す。
- クラウド環境から一部サイト(blender.org等)にはアクセスできない。素材の追加が必要な
  場合は、益田さんにファイルを送ってもらう。
