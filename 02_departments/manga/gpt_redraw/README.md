## 仕上げ方(finish_page.py)
- GPTの絵の灰色を、濃さに比例した大きさの網点にする(段に分けると、境目がまだらになるため)
- まわりに約40pxの白い余白を残し、原稿(1000x1414)に合わせる
- 文字は座標を指定して入れる(例: `python3 finish_page.py 元.png 出力.png 'balloon|930|820|セリフ|28|8'`)
- 全体が灰色っぽい絵は GAMMA=0.6 で明るくする。黒髪が灰色なら BLACK を上げる(髪の濃さを測って決める)
- 2枚から選ぶときは、コマの間で人物の左右の位置がそろっている方を優先する(益田さん指定、2026-11-26)
- 「マスターピース顔」(AIらしいつやつやの量産顔)を避ける。指示文の【守ってほしいこと】に顔の描き方の禁止を入れる。画風の見本はKaggleの原画(style_ref_ep01)だけにし、GPTで描いたページは見本にしない(益田さん指摘、2026-11-26)
