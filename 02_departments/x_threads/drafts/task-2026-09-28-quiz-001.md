## 問題
My grandfather ______ walk five kilometers to school every day when he was young.

## 選択肢
① used to
② is used to
③ used to be
④ was using

## 正解
① used to(〜したものだった、過去の習慣を表す)

## 検算メモ
- 文全体は「祖父は若い頃、毎日学校まで5キロ歩いた"ものだった"」という意味。空欄の直後に動詞の原形"walk"が続いている点がポイント。
- ① used to は "used to + 動詞の原形" の形で「(今はしないが)昔は〜したものだ」という過去の習慣・状態を表す定型表現で、直後に原形動詞walkを取れる。文末の"when he was young"(若い頃)とも時制・意味が完全に一致する。→ 文法・意味ともに成立する唯一の選択肢。
- ② is used to は "be used to + 名詞/動名詞(-ing)" の形で「〜に慣れている」という意味になり、直後に原形動詞は取れない("is used to walking"なら文法的に可)。また現在形isは文末の"when he was young"という過去の文脈とも時制が矛盾する。→ 不適切。
- ③ used to be は "used to be + 名詞/形容詞" の形で「以前は〜だった(状態)」を表し、直後に動詞の原形は取れない("used to be a student"のような形になる)。"used to be walk"は文法的に成立しない。→ 不適切。
- ④ was using は "be using + 名詞(道具・物)" の形で「〜を使っていた」を表す進行形で、直後に動詞の原形は取れない("was using a bicycle"のような形になる)。"was using walk"は文法的に成立しない。→ 不適切。
- 以上より、直後に動詞の原形walkを取れて意味・時制ともに矛盾しないのはused toのみであり、正解は一意に定まる。
