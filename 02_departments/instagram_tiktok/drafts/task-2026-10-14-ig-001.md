## キャプション(投稿時にそのままコピペする本文)

```
古文単語、覚えたのに読めない…を終わらせよう🔥 コツの残り5つはこちら!

6. 例文の中で覚える
 → 文脈ごと覚えると、読解のときに意味を選びやすい

7. 反対語・似た意味の語をセットにする
 → 「をかし」と「あはれ」のように比べると違いが残る

8. 忘れかけた頃に見直す
 → 翌日・3日後・1週間後と間隔をあけて復習しよう

9. 古文を読んだあとに、出てきた単語を確認する
 → 実際の文章で出会った単語は記憶に残りやすい

10. 隠して思い出すテストをする
 → 「見て分かる」から「自分で言える」に変わる

保存して何度も見返してね📌
他の科目も知りたい人はフォローで待っててね!

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
英単語帳、
その使い方で大丈夫?

やりがちなNG勉強法4つ
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 1周目から完璧に覚えようとする
```
1回で覚えるのは難しい。**何周も回す前提**で、1周目は軽く確認する程度でOK。

**3枚目**
```
2 書くだけで満足してしまう
```
ノートに書き写すだけでは、**思い出す練習**にならない。
隠して意味を言う、のほうが定着しやすい。

**4枚目**
```
3 分かる単語まで毎回見直す
```
時間がかかる原因はここ。**覚えていない単語だけ**にチェックをつけて回そう。

**5枚目**
```
4 まとめて一気にやって、そのまま放置する
```
週末にまとめるより、**毎日少しずつ**。
間隔をあけた復習で、忘れにくくなる。

### 3. 締め
```
まとめ
①1周目から完璧を目指さない
②書くだけで終わらせず、思い出す練習をする
③覚えていない単語だけ回す
④毎日少しずつ、間隔をあけて復習する

保存して、英単語帳を開く前に見返してね📌
受験勉強のコツをもっと知りたい人はフォローで待っててね。
