
```
Q2. 1年次から少人数授業やゼミはある?
```
入学後の学び方をイメージできると、
「なぜこの大学か」を具体的に語れるようになる。

**4枚目**
```
Q3. 留学・インターンの参加率は?
```
制度が**あるかどうか**だけでなく、
**実際にどれくらいの学生が使っているか**まで聞いておく。

**5枚目**
```
Q4. 総合型選抜の合格者はどんな学生生活?
```

**入学後のリアルな1日の過ごし方**を聞いておくと安心材料になる。
