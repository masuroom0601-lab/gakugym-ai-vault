```

 → 種類ごとに対策が変わる。まず原因を仕分けするのが復習の第一歩

 → 答えの丸写しは復習した気になるだけ。理由を言葉にすると定着する

 → 人に教えるつもりで書くと、理解のあいまいな部分が見つかる

 → 「気をつける」ではなく「見直しの時間を5分取る」など行動で決める

⑤ 1週間後にもう一度解き直す日付を書き込む
 → 復習の予定まで書いておくと、やりっぱなしを防げる

保存して何度も見返してね📌

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
見直し1 設問の「聞かれ方」を確認する
```
「理由」「説明」「筆者の主張」など、**設問の指示語**を
読み違えていなかったか振り返る。

**3枚目**
```
見直し2 選択肢を切った根拠を言える?
```
正解を選んだ問題でも、**他の選択肢がなぜ誤りか**を
本文の言葉で説明できるか確認する。

**4枚目**
```
見直し3 接続語・対比に線を引き直す
```
**「しかし」「つまり」などの接続語**と対比構造に印を付け直し、
筆者の主張の流れを再確認する。

**5枚目**
```
見直し4 時間配分を振り返る
```
どの大問に何分使ったかを書き出し、**時間をかけすぎた箇所**を
次回の配分に反映する。

### 3. 締め
```
まとめ
①設問の聞かれ方(指示語)を確認する
②選択肢を切った根拠を本文の言葉で説明する

④時間配分を振り返って次回に反映する
