## キャプション(投稿時にそのままコピペする本文)

```
「用語、図とセットで覚えてる?」中間テスト前の理科、この5つで乗り切ろう🧪

① 語句は「現象とセットの図」で覚える
　→ 教科書の図を思い出しながら暗記すると、文章だけで覚えるより忘れにくい
② 計算問題は公式より先に単位変換のパターンを覚える
　→ 公式を覚えていても単位換算でつまずくミスが多い。先にパターン化しておくと得点が安定する

　→ 正解だけ覚え直すより、間違えた理由まで言語化する方が同じミスを繰り返しにくい

　→ バラバラに覚えると混同しやすい。1つの実験のストーリーとして覚えると定着する
```

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
英語
テスト前に見直したい「よくあるミス」
```
キャッチコピー: 「その減点、防げます」

### 2. 中面(1テーマ1枚・解説型)

**2枚目**
```
三単現・複数形の「-s」付け忘れ
```
主語が三人称単数のとき動詞に-sをつけ忘れるミスが最も多い。
見直しの最初のチェックポイントにする。

**3枚目**
```
時制の統一忘れ
```
1文・1段落の中で過去形と現在形が
混ざっていないか確認する。

**4枚目**
```
似ている単語のスペル混同
```
quiet/quite、through/thoughなど
見た目が近い単語の書き間違いが多い。

**5枚目**
```
意味だけ丸暗記して文脈を読み違える
```
単語単体の意味だけで判断せず、
前後の文脈と合っているか確認する。

### 3. 締め
```
まとめ
①三単現・複数形の「-s」付け忘れ
②時制の統一忘れ
③似ている単語のスペル混同
④意味だけ丸暗記して文脈を読み違える

保存して、テスト前日に見返してね📌
他の科目のよくあるミスも知りたい人はフォローで待っててね。
```
