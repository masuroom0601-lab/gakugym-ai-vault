## フィード下書き(カルーセル)

**使用テンプレート: 図解で覚えるシリーズ**(2026-09-18は日にちが偶数のため)

### 1. 表紙
```
漢文
返り点・句法の読み間違い
5選
```

### 2. 中面(1テーマ1枚・図解型)

**2枚目**
```
レ点の後の一・二点の順序を逆に読む
```
レ点は直前の一字だけ先に返す記号。
一・二点と混在すると返る順序を勘違いしやすい。
指でなぞって返る順を確認する。

**3枚目**
```
「不」の後の送り仮名を忘れる
```
「不」は下から返って読む返読文字。
返るときに活用語尾の送り仮名を忘れると
意味が変わってしまう。

**4枚目**
```
使役・受身の句法を見落とす
```
「使」「令」「見」「被」などの句法標識を
素通りすると、主語と動作の向きを
取り違えてしまう。

**5枚目**
```
置き字・助字の意味を無視して読む
```
「者」「也」などの置き字は読まないが
意味は持つ。無視すると文の切れ目や
強調点を読み落とす。

**6枚目**
```
返り点がない箇所を語順通りに読めていない
```
返り点がない部分は原則そのまま上から読む。
思い込みで語順を変えて誤読するケースが多い。

### 3. 締め
```
まとめ
①レ点の後の一・二点の順序を逆に読む
②「不」の後の送り仮名を忘れる
③使役・受身の句法を見落とす
④置き字・助字の意味を無視して読む
⑤返り点がない箇所を語順通りに読めていない

保存して、テスト前日に見返してね📌
他の科目のよくある間違いも知りたい人はフォローで待っててね。
```
