## リール台本(英検語彙・熟語シリーズ)

**タイトル**: なぜ英検準2級の似た単語は間違えやすいのか

**表紙のテーマ文言**: 英検準2級

### 本編(前半5項目・Canva用)

1. lend と borrow
   - 補足: lend は「貸す」、borrow は「借りる」。lend は自分から出ていくイメージ

2. raise と rise
   - 補足: raise は「〜を上げる」(目的語が必要)、rise は「上がる」(自分で上がる)

3. affect と effect
   - 補足: affect は「影響を与える」(動詞)、effect は「影響・効果」(名詞)

4. economic と economical
   - 補足: economic は「経済の」、economical は「経済的な・お得な」

5. sensible と sensitive
   - 補足: sensible は「分別のある」、sensitive は「敏感な」。形が似ていても意味は別物

6. historic と historical
 → historic は「歴史的に重要な」、historical は「歴史に関する」。historic moment(歴史的瞬間)はセットで覚えよう

7. principal と principle
 → principal は「校長・主な」、principle は「原則」。校長は pal(仲間)がつくほうと覚えるとラク

8. fit と suit
 → fit は「サイズが合う」、suit は「似合う・都合が合う」。This color suits you. は定番表現

9. beside と besides
 → beside は「〜のそばに」、besides は「その上・〜以外に」。s がつくと「追加」のイメージ

10. lay と lie
 → lay は「〜を置く」(目的語あり)、lie は「横になる」。過去形が lay と laid で入れ替わるので要注意

どれも見た目が似ているだけで、使い方は別物。品詞や「自分でする/他にする」の違いとセットで覚えると、4択でも迷いにくくなるよ✨

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 入室したら「あいさつ」から笑顔で
```
まず大きな声で**あいさつ**をすれば、緊張がほぐれる。
第一印象も良くなり、**そのあとの会話**が楽になる。

**3枚目**
```
2 音読は「ゆっくり・はっきり」
```
速く読もうとすると**つまずく**。
一語ずつ**区切って**読むほうが、聞き取りやすく印象も良い。

**4枚目**
```
3 質問には「聞かれたこと」だけ答える
```
長く話そうとして**迷子**にならない。
まず**主語と動詞**のある短い文で、はっきり答えよう。

**5枚目**
```
4 聞き取れなかったら「聞き返す」
```
**黙り込む**のがいちばんもったいない。
**Pardon?** と聞き返せば、もう一度チャンスがもらえる。

### 3. 締め
