### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 文章ではなく「キーワード」だけ覚える
```
一言一句の暗記は、**1か所忘れると頭が真っ白**になりやすい。
話の**骨組みとなる3〜4個の言葉**だけ押さえておく。

**3枚目**
```
2 「結論→理由→具体例」の型に当てはめる
```
どんな質問でも、**この順番**で話すと伝わりやすい。
型を覚えておけば、**想定外の質問にも対応**できる。

**4枚目**
```
3 声に出して、人に聞いてもらう
```
頭の中で整理しても、**口に出すと詰まる**ことが多い。
家族や先生に聞いてもらい、**分かりにくい所**を指摘してもらう。

**5枚目**
```
4 自分の経験を「エピソード」で語れるようにしておく
```
きれいな言葉より、**実際にやったこと**のほうが印象に残る。
**きっかけ・行動・気づき**をセットで話せるよう準備する。

### 3. 締め
