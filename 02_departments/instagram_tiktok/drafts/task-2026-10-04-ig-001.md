## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
模試の点数が悪かった日
切り替え方4つ

落ち込むのは今日だけ
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 まず「悔しい」を認める
```
悪い点数を見て落ち込むのは、**真剣に取り組んだ証拠**。
気持ちを無理に押し込めず、今日は区切りをつけて休む。

**3枚目**
```
2 点数ではなく「失点の原因」を見る
```
点数そのものより、**なぜ落としたか**が大事。
知識不足・時間切れ・ケアレスのどれかに分けるだけでOK。

**4枚目**
```
3 直せる失点を3つだけ選ぶ
```
全部を直そうとすると、手が止まる。
**次までに直せそうなもの**だけに絞ると、動き出しやすい。

**5枚目**
```
4 次の模試までの予定に入れる
```
「やること」を**日付つきで予定に入れる**。
決めた瞬間に、不安は「やるべきこと」に変わる。

### 3. 締め
```
まとめ
①まず「悔しい」を認める
②点数ではなく「失点の原因」を見る
③直せる失点を3つだけ選ぶ
④次の模試までの予定に入れる

保存して、点数に落ち込んだ日に見返してね📌
受験生活のコツをもっと知りたい人はフォローで待っててね。
```
