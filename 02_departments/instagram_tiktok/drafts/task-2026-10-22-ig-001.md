## リール台本

**表紙のテーマ文言**: 期末テスト対策

### 本編(Canva用・前半5項目)

**1.** メイン文: `1. まずテスト範囲と日程を全部書き出す`
補足文: `敵を知らないと、計画は立てられないよ`

**2.** メイン文: `2. 4週間前は「範囲の全体像」をつかむ`
補足文: `完璧を目指さず、まず一周ざっと見ておくのがコツだよ`

**3.** メイン文: `3. 提出物は最初の1週間で終わらせる`
補足文: `直前に回すと、暗記の時間が削られてしまうよ`

**4.** メイン文: `4. 1日の勉強量は「ひかえめ」に決める`
補足文: `できない計画は続かないから、7割できればOKくらいが丁度いいよ`

**5.** メイン文: `5. 計画には「予備日」を週1日つくる`
補足文: `遅れた分を取り戻せる日があると、気持ちがラクだよ`

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
志望理由書、
最初の一文で止まってない?

書き出せる4つのコツ
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 「きっかけの体験」から書き出す
```
いきなり立派な文章を書こうとしない。
**自分が興味を持った具体的な出来事**を、まず箇条書きにする。

**3枚目**
```
2 「なぜ」を3回くり返して深掘りする
```
「興味がある」だけでは、他の人と似た内容になりやすい。
**「なぜそう思った?」を3回**自分に問いかけてみる。

**4枚目**
```
3 大学で学びたいことを具体的にする
```
「〇〇について学びたい」だけでは弱い。
**どの学部・どの授業・どの先生か**まで調べて書く。

**5枚目**
```
4 書いたら声に出して読んでみる
```
目で読むだけでは、不自然な部分に気づきにくい。
**声に出す**と、分かりにくい文やつながりの悪い部分が見えてくる。

### 3. 締め
```
まとめ
①「きっかけの体験」から書き出す
②「なぜ」を3回くり返して深掘りする
③大学で学びたいことを具体的にする
④書いたら声に出して読んでみる

保存して、志望理由書を書くときに見返してね📌

```
