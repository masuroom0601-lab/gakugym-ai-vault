## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
英検リスニングは
聞き逃したあとで差がつく

焦らず次に進む練習をしよう
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 聞き逃しても引きずらない
```
わからない問題に**気を取られる**と、次の放送まで聞き逃す。
**割り切って**次の問題に気持ちを切り替えよう。

**3枚目**
```
2 メモは「数字・名前」だけにする
```
全部書こうとすると、**聞く手**が止まる。
**数字**・**時間**・**場所**など、答えに関わる情報だけを短く書こう。

**4枚目**
```
3 シャドーイングで英語の音に慣れる
```
音声のあとを追って、**そのまま**口に出してみよう。
**音のつながり**に慣れると、聞き取れる英語が増えていく。

**5枚目**
```
4 聞き取れなかった所をスクリプトで確認する
```
解いたあとは**スクリプト**を見て、聞き取れなかった箇所を探そう。
**知らない単語**か**聞こえなかった音**かを分けると、直す点がわかる。

### 3. 締め
```
まとめ
①聞き逃しても引きずらず、次の問題へ
②メモは数字・名前など答えに関わる情報だけ
③シャドーイングで英語の音に慣れる
④聞き取れなかった所をスクリプトで確認する

保存して、英検のリスニング対策に使ってね📌
英検の対策をもっと知りたい人はフォローで待っててね。
```
