### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 まず時代を「誰が政治を動かしたか」で一言にする
```
細かい用語から入ると、全体像がつかめず混乱しやすい。
**「貴族→武士→…」のように担い手**で時代を整理すると、土台ができる。

**3枚目**
```
2 出来事は「原因→結果」の矢印でつなぐ
```
出来事を1つずつ覚えると、順番があいまいになる。
**「なぜ起きて、何が変わったか」**をセットにすると忘れにくい。

**4枚目**
```
3 年号は、節目になる数個だけ先に覚える
```
全部の年号を同時に覚えようとすると、途中で挫折しやすい。
**時代の区切りとなる年号**を軸にして、他の出来事を前後に置いていく。

**5枚目**
```
4 覚えたら、白紙に年表を自分で書き出す
```
教科書を眺めるだけでは、覚えた気になりやすい。
**白紙に再現**して抜けた所だけ見直すと、効率よく定着する。
