### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 先に自分の答えを考えてから選択肢を見る
```
選択肢を先に読むと、**もっともらしい文に引っ張られる**。
本文の根拠を探して、**自分の言葉で答えの方向性**を決めておく。

**3枚目**
```
2 選択肢の「根拠」を本文に探す
```
「なんとなく合ってそう」で選ばない。
**本文のどこに書いてあるか**を指させない選択肢は消す。

**4枚目**
```
3 「すべて」「必ず」などの強い言葉に注意する
```
言い切りが強い選択肢は、**本文と少しズレている**ことが多い。
その言葉が**本文で言い切れているか**を確認する。

**5枚目**
```
4 一部だけ正しい選択肢に気をつける
```
前半は合っていても、**後半が本文と違う**パターンがよくある。
**文の最初から最後まで**、一つずつ照らし合わせる。

### 3. 締め
