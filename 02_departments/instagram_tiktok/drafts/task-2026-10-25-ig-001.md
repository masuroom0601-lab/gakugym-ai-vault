## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙

英語の文法、
同じところで落としてない?

```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 三単現の s を付け忘れる
```
主語が **he / she / it / 単数名詞** のときの現在形は、動詞に s。
書き終えたら、**主語に線を引いて**確認する。

**3枚目**
```
2 過去形と過去分詞を混同する
```
受動態・現在完了では **過去分詞** を使う。
動詞は **「原形・過去形・過去分詞」の3つセット**で覚える。

**4枚目**
```
3 疑問文・否定文で動詞の形を戻し忘れる
```
did や does のあとの動詞は **原形** に戻る。
「did + 過去形」と書いていないか、**見直しで必ずチェック**する。

**5枚目**
```
4 冠詞(a / the)と複数形を見落とす
```
数えられる名詞は **a か複数形** が基本。
最後の見直しで、**名詞に a / the / s がついているか**だけを見る時間をつくる。

### 3. 締め
```
まとめ
①三単現の s を付け忘れる
②過去形と過去分詞を混同する
③疑問文・否定文で動詞の形を戻し忘れる
④冠詞(a / the)と複数形を見落とす
