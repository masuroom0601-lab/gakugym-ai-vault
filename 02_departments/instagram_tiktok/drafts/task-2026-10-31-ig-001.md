## リール台本(英検語彙・熟語シリーズ)

**タイトル**: 英検準1級の紛らわしい単語はスペルの違いで見分ける

**表紙のテーマ文言**: 英検準1級

### 本編(前半5項目・Canva用)

1. compliment と complement
   - 補足: compliment は「称賛」、complement は「補うもの」。i は「愛(I)のある褒め言葉」と覚えよう

2. elicit と illicit
   - 補足: elicit は「引き出す」(動詞)、illicit は「違法の」(形容詞)。品詞で見分けられる

3. disinterested と uninterested
   - 補足: disinterested は「公平な・私心のない」、uninterested は「無関心な」

4. flaunt と flout
   - 補足: flaunt は「見せびらかす」、flout は「(規則を)無視する」。ルール破りは flout

5. censor と censure
   - 補足: censor は「検閲する」、censure は「厳しく非難する」。語尾の -or / -ure で区別

6. continual と continuous
 → continual は「断続的に繰り返す」、continuous は「途切れず続く」。雨がやんだり降ったりなら continual

7. emigrate と immigrate
 → emigrate は「(自国から)出ていく」、immigrate は「(他国から)入ってくる」。e は exit、i は in で覚えよう

8. prescribe と proscribe
 → prescribe は「処方する・規定する」、proscribe は「禁止する」。p-re は「前もって書く」、p-ro は「禁止」

9. eminent と imminent
 → eminent は「著名な」、imminent は「差し迫った」。imminent danger(目前の危険)はセットで覚えるとラク

10. ensure と insure
 → ensure は「確実にする」、insure は「保険をかける」。ensure that 〜 の形でよく出るよ

似ているのは見た目だけで、意味は別物。語源や品詞のヒントとセットで覚えると、4択でも迷いにくくなるよ✨

```

```
