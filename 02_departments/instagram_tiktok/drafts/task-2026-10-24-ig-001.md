## リール台本

**タイトル**: テスト前の計画が続かない人の習慣

**表紙のテーマ文言**: 勉強計画

### 本編(Canva用・前半5項目)

**1.** メイン文: `1. 計画を「1日の量」まで細かく分けていない`
補足文: `「今週は英語」では動けない。今日やる量まで落とそう`

**2.** メイン文: `2. 1日の予定をぎっしり詰めこみすぎる`
補足文: `できなかった日が続くと、一気にやる気が切れるよ`

**3.** メイン文: `3. 予備日を作っていない`
補足文: `週に1日の空白が、遅れを取り戻す余裕になるよ`

**4.** メイン文: `4. 計画を立てるだけで満足している`
補足文: `立てた直後の「今日の最初の1つ」をすぐ始めよう`

**5.** メイン文: `5. 始める時間が毎日バラバラ`
補足文: `時間を固定すると、悩まずに机に向かえるよ`

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
現代文の記述、
なんとなくで書いてない?

点を落とさない4つのコツ
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 まず設問が聞いていることに線を引く
```
「理由」なのか「説明」なのかで、書く中身は変わる。
**設問の指示**を押さえてから本文に戻ろう。

**3枚目**
```
2 解答の根拠を本文から探す
```
自分の感想や常識で書くと、点にならない。
**本文中の言葉**を根拠にして答えを組み立てる。

**4枚目**
```
3 指示語・対比に注目してつなぐ
```
「これ」「一方」などは、**論理の道しるべ**。
つながりを追うと、筆者の主張が見えてくる。

**5枚目**
```
4 書いたあとに設問と照らして見直す
```
聞かれたことに答えているか、**最後に確認**する。
字数や文末の形をそろえるだけで、減点を防げる。

### 3. 締め
```
まとめ
①設問が聞いていることに線を引く
②解答の根拠を本文から探す
③指示語・対比に注目してつなぐ
④書いたあとに設問と照らして見直す

保存して、現代文の記述の前に見返してね📌
現代文の勉強法をもっと知りたい人はフォローで待っててね。
```
