## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
なぜ英検の単語は
覚えてもすぐ忘れるのか

原因は「覚え方」にあった
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 1回で覚えようとしている
```
人は**覚えてすぐ**から忘れ始める。
**1日後・3日後・1週間後**と間隔をあけて、くり返し見直そう。

**3枚目**
```
2 日本語訳だけで覚えている
```
単語と訳だけだと、**使い方**が頭に残らない。
**短い例文**ごと覚えると、長文や並べ替えでも思い出しやすい。

**4枚目**
```
3 見るだけで終わらせている
```
眺めるだけでは**覚えた気**になるだけ。
**声に出す**、**書く**で、自分で思い出す練習をしよう。

**5枚目**
```
4 間違えた単語を放置している
```
できた単語より、**間違えた単語**を優先しよう。
**目印**をつけて、次の復習で真っ先に確認する。

### 3. 締め
```
まとめ
①1回で終わらせず、間隔をあけて見直す
②日本語訳だけでなく、例文ごと覚える
③見るだけでなく、声に出す・書く
④間違えた単語を優先して復習する

保存して、英検の単語学習に使ってね📌
英検の対策をもっと知りたい人はフォローで待っててね。
```
