## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
英単語、
丸暗記してない?

語源で覚える4つのコツ
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 接頭辞の意味を押さえる
```
**re-(再び)**、**pre-(前に)**、**un-(否定)** など。
意味を知っているだけで、初めて見る単語も推測できる。

**3枚目**
```
2 語根(中心の部分)でグループ化する
```
たとえば **port(運ぶ)** なら、export・import・transport。
**1つの核から、まとめて覚えられる**。

**4枚目**
```
3 接尾辞で品詞を見分ける
```
**-tion**は名詞、**-ful**は形容詞など。
読解や空所補充で、**品詞のあたり**をつけやすくなる。

**5枚目**
```
4 パーツに分けて意味を予想してから答えを見る
```
いきなり訳を見ない。
**自分で推測する一手間**が、記憶に残るきっかけになる。

### 3. 締め
```
まとめ
①接頭辞の意味を押さえる
②語根でまとめて覚える
③接尾辞で品詞を見分ける
④パーツから意味を予想してから答え合わせ

保存して、単語帳を開くときに見返してね📌
英語の勉強法をもっと知りたい人はフォローで待っててね。
```
