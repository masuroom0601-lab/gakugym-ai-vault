## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
勉強を始められない人へ
ハードルを下げるコツ4つ

「やる気」を待たなくていい
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 最初の5分だけやると決める
```
「今日は2時間やる」と決めると、始める前に疲れてしまう。
**まず5分だけ**と決めると、手が動き出して、そのまま続くことが多い。

**3枚目**
```
2 一番簡単な問題から始める
```
難しい問題から入ると、手が止まって嫌になる。
**解ける問題から先に1つ解く**と、勢いがついて次に進みやすい。

**4枚目**
```
3 勉強を始める時間を毎日固定する
```
「いつやるか」を毎回考えると、先延ばしになりやすい。
**夕食後・帰宅後など時間を決めておく**と、考えずに始められる。

**5枚目**
```
4 やることを「1行」に小さく分ける
```
「英語をやる」では何から手をつけるか迷う。
**「単語を20個覚える」まで具体的に**書くと、すぐ取りかかれる。

### 3. 締め
```
まとめ
①最初の5分だけやると決める
②一番簡単な問題から始める
③勉強を始める時間を毎日固定する
④やることを「1行」に小さく分ける

保存して、やる気が出ない日に見返してね📌
受験生活のコツをもっと知りたい人はフォローで待っててね。
```
