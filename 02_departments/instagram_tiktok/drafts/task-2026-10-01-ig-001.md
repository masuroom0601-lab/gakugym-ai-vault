## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
復習ノート
見返す習慣づくり4つ

作って終わりを卒業しよう
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
習慣1 見返す日をノートに先に書く
```
ノートを作った日に、**1週間後・2週間後の日付**を余白に書いておく。
見返す予定が先に決まっていれば忘れない。

**3枚目**
```
習慣2 1ページ1テーマに絞る
```
1ページに詰め込むと見返す気が失せる。
**1ページ=1つのミス**にして、ひと目で内容がわかる形にする。

**4枚目**
```
習慣3 見返したら印を付ける
```
見返すたびに日付や**チェックマーク**を残す。
印が増えるほど、続いている実感が積み上がる。

**5枚目**
```
習慣4 見返す場所と時間を固定する
```
「寝る前の5分」「朝の電車で」など、**いつでも同じタイミング**に決める。
決まった流れに組み込むと習慣になる。

### 3. 締め
```
まとめ
①見返す日をノートに先に書く
②1ページ1テーマに絞る
③見返したら印を付ける
④見返す場所と時間を固定する

保存して、ノートを作ったあとに見返してね📌
受験生活のコツをもっと知りたい人はフォローで待っててね。
```
