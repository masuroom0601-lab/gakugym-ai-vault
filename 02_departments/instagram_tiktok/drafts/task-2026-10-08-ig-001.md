## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
集中が切れない人の
休憩の取り方4つ

休むほど、次の集中が深くなる
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 休憩は「疲れてから」でなく「先に」決める
```
疲れ切ってから休むと、回復に時間がかかる。
**45〜50分勉強したら10分休む**など、先に区切りを決めておく。

**3枚目**
```
2 休憩中は体を動かす
```
座ったまま休んでも、頭と体は切り替わりにくい。
**立つ・歩く・軽く伸びをする**と、気持ちがリセットされる。

**4枚目**
```
3 休憩の終わりに「次にやること」を決めておく
```
再開時に「何からやろう」と迷うと、時間がずるずる延びる。
**休む前に、次の1問・次のページをメモしておく**と、すぐ戻れる。

**5枚目**
```
4 休憩に使う時間と場所を決める
```
休憩のたびに場所や内容が変わると、だらだら長引きやすい。
**タイマーをかけ、机から離れた同じ場所で休む**と、切り替えが安定する。

### 3. 締め
```
まとめ
①休憩は「疲れてから」でなく「先に」決める
②休憩中は体を動かす
③休憩の終わりに「次にやること」を決めておく
④休憩に使う時間と場所を決める

保存して、集中が切れた日に見返してね📌
受験生活のコツをもっと知りたい人はフォローで待っててね。
```
