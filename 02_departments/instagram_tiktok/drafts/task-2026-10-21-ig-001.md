## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
日本史の出来事、
バラバラに覚えてない?

流れで覚える4つのコツ
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 「原因→結果」でつなげて覚える
```
出来事を単独で覚えると、すぐ忘れてしまう。
**なぜ起きたか、その後どうなったか**をセットにする。

**3枚目**
```
2 年表は「大きな区切り」から作る
```
最初から細かく覚えようとしない。
まず**時代ごとの区切り**を押さえて、そこに出来事を足していく。

**4枚目**
```
3 人物は「何をした人か」を一言で言う
```
名前と功績をバラバラに覚えると混同しやすい。
**「〇〇をした人」**と一言で言えるようにしておく。

**5枚目**
```
4 白紙に流れを書き出して確認する
```
教科書を眺めるだけでは「分かったつもり」になりやすい。
**白紙に自分で書く**と、抜けている部分が見える。

### 3. 締め
```
まとめ
①「原因→結果」でつなげて覚える
②年表は「大きな区切り」から作る
③人物は「何をした人か」を一言で言う
④白紙に流れを書き出して確認する

保存して、日本史の勉強前に見返してね📌
```
