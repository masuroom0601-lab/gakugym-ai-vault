## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```

切らさないコツ4つ

席と時間の決め方で変わる
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 席は「壁側・人目が少ない場所」を選ぶ
```
視界に入る人が少ないと、周りの動きに気を取られにくい。
**入口や通路から遠い席**を、いつもの定位置にする。

**3枚目**
```
2 持ち込む教材は最初に決める
```
自習室に着いてから「何やろう」と考えると、時間がもったいない。
**今日やる範囲を前日に決めて**、その教材だけをカバンに入れる。

**4枚目**
```
3 50分やったら10分休む
```
ずっと座り続けると、後半は集中が落ちる。
**50分の勉強+10分の休憩**で区切ると、最後まで続けやすい。

**5枚目**
```
4 帰る前に、次回の最初の一問を決める
```
やめる時に「次はここから」と書いておく。
**次に座った時すぐ手が動く**ので、始めるまでの迷いがなくなる。

