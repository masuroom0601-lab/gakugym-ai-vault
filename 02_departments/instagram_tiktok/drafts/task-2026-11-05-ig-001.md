## リール台本(英検語彙・熟語シリーズ)

**タイトル**: なぜ熟語は混ざる?

**表紙のテーマ文言**: 英検2級

### 本編(前半5項目・Canva用)

1. put off と call off
   - 補足: put off は「延期する」、call off は「中止する」。やめるのか、先送りなのかが違い

2. look for と look after
   - 補足: look for は「探す」、look after は「世話をする」。for は探す先、after は面倒を見る相手

3. run out of と run into
   - 補足: run out of は「使い果たす」、run into は「偶然出会う」。out of は中身がなくなるイメージ

4. come up with と come across
   - 補足: come up with は「思いつく」、come across は「偶然見つける」。自分で出すか、出会うかの違い

5. carry out と carry on
   - 補足: carry out は「実行する」、carry on は「続ける」。out は最後までやり切るイメージ

## キャプション(投稿時にそのままコピペする本文)

```
2級の熟語、なんで似たものばかりで混ざっちゃうの…?😵

6. take after と take over
 → take after は「(親などに)似ている」、take over は「引き継ぐ」。after は後を追うように似るイメージ

7. get over と get along with
 → get over は「乗り越える・立ち直る」、get along with は「(人と)うまくやる」。with のあとには人が来やすいよ

8. bring up と bring about
 → bring up は「育てる・話題に出す」、bring about は「引き起こす」。結果を生むのが bring about

9. give up と give in
 → give up は「あきらめる・やめる」、give in は「屈する・折れる」。give in to ~ の形でも出るよ

10. turn up と turn down
 → turn up は「音量を上げる・現れる」、turn down は「断る・音量を下げる」。up と down で反対の動きになるよ

熟語は「動詞+前置詞・副詞」のイメージ(out=外へ/up=上へ・出現/on=続く)で区別すると、4択でも迷いにくくなるよ✨

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
英検の長文は
設問から読む

時間が足りない人のための解き方
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 まず「設問」だけ先に読む
```
本文より先に、**設問**をざっと見ておこう。
何を探しながら読むかが決まって、**読みが速く**なる。

**3枚目**
```
2 各段落の「最初の1文」に注目する
```
段落の**冒頭**には、その段落の**主題**が出やすい。
全体の流れをつかんでから、細部を読もう。

**4枚目**
```
3 答えの「根拠」に線を引く
```
正解は本文の**言い換え**になっていることが多い。
本文の**根拠の箇所**を見つけてから選択肢を選ぼう。

**5枚目**
```
4 迷ったら「飛ばして」先へ進む
```
1問に**時間をかけすぎる**と、最後の問題に届かない。
迷ったら**印だけ**つけて、先に解ける問題から進めよう。

### 3. 締め
```
まとめ
①まず「設問」だけ先に読む
②各段落の「最初の1文」に注目する
③答えの「根拠」に線を引く
④迷ったら「飛ばして」先へ進む

保存して、英検の長文対策に使ってね📌
