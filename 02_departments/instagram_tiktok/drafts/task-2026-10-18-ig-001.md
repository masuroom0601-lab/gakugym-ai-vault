## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
英単語、覚えたのに
すぐ忘れてない?

忘れない復習タイミング4つ
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 覚えた「当日中」にもう一度見る
```
時間がたつほど、**記憶は一気に薄れていく**。
寝る前の**1〜2分の見直し**だけでも、定着が変わる。

**3枚目**
```
2 翌日・3日後・1週間後に見直す
```
**間隔を少しずつあけて**思い出すのが、忘れにくくなる近道。
カレンダーや単語帳に**復習日**を書いておく。

**4枚目**
```
3 「忘れかけた頃」に思い出す
```
完璧に覚えている単語を何度も見るのは**時間のムダ**。
**「あれ、なんだっけ?」となる頃**に確認するのが効果的。

**5枚目**
```
4 間違えた単語だけを繰り返す
```
全部をやり直すより、**間違えた単語に絞る**ほうが速い。
**付箋やチェック印**をつけ、そこだけ毎日回す。

### 3. 締め
```
まとめ
①覚えた当日中にもう一度見る
②翌日・3日後・1週間後に見直す
③忘れかけた頃に思い出す
④間違えた単語だけを繰り返す

保存して、単語帳を開く前に見返してね📌
英語の勉強法をもっと知りたい人はフォローで待っててね。
```
