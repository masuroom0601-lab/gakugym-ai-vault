**表紙のテーマ文言**: 現代文

### 本編(Canva用・前半5項目)

**1.** メイン文: `1. 「なんとなく」で選択肢を選んでいる`
補足文: `感覚で解くと、点数が安定しないんだよね`

**2.** メイン文: `2. 答えの根拠を本文に探していない`
補足文: `「どこに書いてある?」と線を引く習慣をつけよう`

**3.** メイン文: `3. 接続詞・指示語を読み飛ばしている`
補足文: `「しかし」「つまり」の前後に、筆者の主張が出やすいよ`

 → 「必ず」「すべて」「絶対」など極端な言葉が入った選択肢は、一度疑ってみよう

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
古文の期末テスト、
点を落とさない見直し4選

助動詞と敬語の「ここ」を確認しよう
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 「ぬ」「ね」は接続で見分ける
```
**直前の活用形**を見る。**連用形**につくなら完了の「ぬ」。**未然形**につくなら打消「ず」の已然形「ね」。
訳してから、**前の語の形**を必ず確かめる。

**3枚目**
```
2 「なり」は接続で判別する
```
**終止形**につくなら **伝聞・推定**。**体言・連体形**につくなら **断定**。
「なり」を見つけたら、**まず直前の語**に印をつける。

**4枚目**
```
3 「る・らる」は4つの意味を疑う
```
**受身・尊敬・可能・自発**の4つ。
**主語が誰か**、**文末に打消があるか**を手がかりに絞る。

**5枚目**
```
4 敬語は「誰から誰へ」を確認する
```
**尊敬語**は動作をする人を高め、**謙譲語**は動作を受ける人を高める。
**誰の動作か**を先に決めてから、敬語の種類を判断する。

### 3. 締め
```
まとめ
①「ぬ」「ね」は接続で見分ける
②「なり」は接続で判別する
③「る・らる」は4つの意味を疑う
④敬語は「誰から誰へ」を確認する

保存して、テスト前の見直しに使ってね📌

```
