## リール台本(英検語彙・熟語シリーズ)

**タイトル**: 似た動詞はペアで覚える

**表紙のテーマ文言**: 英検3級

### 本編(前半5項目・Canva用)

1. see と look
   - 補足: see は「自然に目に入る」、look は「意識して視線を向ける」。意志があるかが違い

2. hear と listen
   - 補足: hear は「聞こえる」、listen は「耳を傾ける」。listen は to が必要だよ

3. say と tell
   - 補足: say は「言葉を言う」、tell は「人に伝える」。tell の後ろには人が来る

4. borrow と lend
   - 補足: borrow は「借りる」、lend は「貸す」。借りる側か、貸す側かで選ぼう

5. bring と take
   - 補足: bring は「持ってくる」、take は「持っていく」。向かう先が自分かどうかが分かれ目

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 時間を計って本番形式で解く
```
解く前に**制限時間**を決めて、本番と同じ流れで取り組もう。
時間配分の**感覚**がつかめて、本番でも焦りにくくなる。

**3枚目**
```
2 間違えた「理由」を書き出す
```
ただ丸つけするだけで終わらせない。
**知識不足**か**ケアレスミス**かを分けて書くと、次に直すべき点が見える。

**4枚目**
```
3 わからなかった表現をノートにまとめる
```
知らなかった**単語**や**表現**は、その場で1冊にまとめよう。
本番前に**見返す1冊**が、いちばん頼れる対策になる。

**5枚目**
```
4 数日後にもう一度解き直す
```
**同じ問題**を数日あけて解き直すと、記憶に残りやすい。
解き直しで**正解できるか**が、定着の目安だよ。

