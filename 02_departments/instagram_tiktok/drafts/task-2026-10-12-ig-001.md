## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
古文は"主語探し"から
読解4ステップ

なんとなく読むのをやめると、訳せるようになる
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 まず文末の「助動詞・動詞」に印をつける
```
文の骨組みは、最後の動詞や助動詞に出る。
**文末に印**をつけてから読むと、1文の区切りがつかみやすい。

**3枚目**
```
2 省略された「主語」を補って書き込む
```
古文は主語がよく省略される。
**「誰が」をメモ**しながら読むと、場面の流れがぶれにくい。

**4枚目**
```
3 敬語の種類から「誰が誰に」を判断する
```
尊敬語・謙譲語が分かると、登場人物の上下関係が見える。
**敬語を手がかり**にすると、主語を絞り込みやすい。

**5枚目**
```
4 読んだあと、1文ずつ現代語に直して確認する
```
なんとなく分かった気になりやすいのが古文。
**自分の言葉で訳し直す**と、分かっていない所がはっきりする。

### 3. 締め
```
まとめ
①まず文末の「助動詞・動詞」に印をつける
②省略された「主語」を補って書き込む
③敬語の種類から「誰が誰に」を判断する
④読んだあと、1文ずつ現代語に直して確認する

保存して、古文を読む前に見返してね📌
```
