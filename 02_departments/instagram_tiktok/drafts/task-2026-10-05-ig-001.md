## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
模試の復習が終わらない人へ
30分で終えるコツ4つ

完璧より、続く復習を
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 時間を先に決める
```
「終わるまでやる」ではなく、**30分でタイマーをセット**。
時間を区切ると、集中して手が動く。

**3枚目**
```
2 間違えた問題だけに絞る
```
正解した問題まで全部見直すと、時間が足りない。
まずは**間違えた問題だけ**に集中する。

**4枚目**
```
3 原因を一言でメモする
```
長い解説は書かない。**「知識不足」「時間切れ」「ケアレス」**など、一言でOK。
一言なら、次に見返す時もすぐ分かる。

**5枚目**
```
4 解き直しは翌日以降に回す
```
その日は**原因の整理まで**で終わらせる。
解き直しは翌日に回すと、負担が軽くなって続けやすい。

### 3. 締め
```
まとめ
①時間を先に決める
②間違えた問題だけに絞る
③原因を一言でメモする
④解き直しは翌日以降に回す

保存して、模試の復習で迷った時に見返してね📌
受験生活のコツをもっと知りたい人はフォローで待っててね。
```
