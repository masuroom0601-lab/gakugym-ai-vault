## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
模試後1週間
復習スケジュール4ステップ

直しを後回しにしない
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
ステップ1 当日〜翌日:自己採点と答案の確認
```
記憶が新しいうちに、**自己採点と解き方の振り返り**を済ませる。
「どこで迷ったか」をメモしておくと、後の復習が速い。

**3枚目**
```
ステップ2 3日以内:間違い直しを終える
```
解説を読んで、**自分の言葉で解き直す**。
3日を過ぎると、なぜ間違えたかを忘れてしまう。

**4枚目**
```
ステップ3 5日目:復習ノートを1ページにまとめる
```
間違えた原因を**パターン別に1ページへ整理**する。
ノートは増やすより、見返せる量に絞る。

**5枚目**
```
ステップ4 7日目:同じ問題をもう一度解く
```
1週間後に**白紙の状態から解き直し**、解けるかを確認する。
解けなかった問題だけが、次の復習の対象になる。

### 3. 締め
```
まとめ
①当日〜翌日:自己採点と答案の確認
②3日以内:間違い直しを終える
③5日目:復習ノートを1ページにまとめる
④7日目:同じ問題をもう一度解く

保存して、模試が返ってきたら見返してね📌
受験生活のコツをもっと知りたい人はフォローで待っててね。
```
