## リール台本(英検語彙・熟語シリーズ)

**タイトル**: 形が似た単語、知ってる?

**表紙のテーマ文言**: 英検準1級

### 本編(前半5項目・Canva用)

1. imply と infer
   - 補足: imply は「ほのめかす」、infer は「推論する」。言う側か、読み取る側かの違い

2. adapt と adopt
   - 補足: adapt は「適応する」、adopt は「採用する」。1文字違いで意味は別物

3. affect と effect
   - 補足: affect は動詞で「影響する」、effect は名詞で「影響・効果」。品詞で見分けよう

4. sensible と sensitive
   - 補足: sensible は「分別のある」、sensitive は「敏感な」。語尾で意味が分かれる

5. historic と historical
   - 補足: historic は「歴史的に重要な」、historical は「歴史に関する」。重要かどうかが分かれ目

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```

減点を防ぐコツ4選

```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 指定の「語数」と「条件」を守る
```
語数が**少なすぎ・多すぎ**だと減点されることがある。
問題文の**条件**(理由の数など)も必ず確認しよう。

**3枚目**
```
2 「意見→理由→結論」の順で書く
```
最初に**自分の意見**をはっきり書く。
次に**理由**を述べ、最後に**結論**でまとめよう。

**4枚目**
```
3 難しい表現より「正確さ」を優先する
```
背伸びした表現で**ミス**をするより、知っている表現を**正確に**使うほうが評価されやすい。
**スペルと文法**が合っているか意識しよう。

**5枚目**
```
4 最後に「見直し」の時間を残す
```
書き終えたら、**単数・複数**やスペルのミスを確認しよう。
**1分**の見直しで防げる減点は意外と多い。

### 3. 締め
```
まとめ
①指定の「語数」と「条件」を守る
②「意見→理由→結論」の順で書く
③難しい表現より「正確さ」を優先する
```
