## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
英語が集中して続く
1時間の組み立て方4つ

順番を変えるだけで、後半まで頭が動く
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 最初の5分は「前回の復習」から始める
```
いきなり新しい内容に入ると、助走なしで疲れやすい。
**単語や例文の見直しから入る**と、英語モードに切り替わる。

**3枚目**
```
2 頭が冴えている前半に、一番重い長文・文法を置く
```
難しい内容を後半に回すと、集中が切れて雑になりやすい。
**長文読解や苦手な文法は、最初の20〜30分に**やる。

**4枚目**
```
3 途中で「読む→書く→声に出す」と作業を変える
```
同じ作業を続けると飽きて、集中が落ちる。
**長文のあとに英作文、最後に音読**と切り替えると、頭が疲れにくい。

**5枚目**
```
4 最後の5分で「今日覚えたこと」を声に出して確認する
```
やりっぱなしだと、次の日には抜けやすい。
**覚えた単語・文法を口に出して言う**と、記憶が定着しやすい。

### 3. 締め
```
まとめ
①最初の5分は「前回の復習」から始める
②頭が冴えている前半に、一番重い長文・文法を置く
③途中で「読む→書く→声に出す」と作業を変える
④最後の5分で「今日覚えたこと」を声に出して確認する

保存して、英語の勉強の前に見返してね📌

```
