## キャプション(投稿時にそのままコピペする本文)

```
「模試の結果、見て終わりにしてない?」返ってきたその日の動き方で、次の模試が変わる。やること4つ📋

① 判定や偏差値より先に「大問別の得点」を見る
 → 総合点だけでは弱点が見えない。どの大問で落としたかが復習の出発点

② 間違いを「今すぐ直せる/時間がかかる」に分ける
 → 見落としはすぐ修正、知識の穴は計画的に。仕分けすると迷わない

③ その日のうちに解き直す問題を3問だけ決める
 → 全部やろうとすると挫折する。まず3問、記憶が新しいうちに解き直す

④ 次の模試までの復習予定をカレンダーに書き込む
 → 予定にしてしまえば「やろうと思って終わり」を防げる

保存して何度も見返してね📌
受験生活のコツをもっと知りたい人はフォローで待っててね!

#模試 #模試復習 #勉強法 #受験勉強 #学ジム
```

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
英語
模試の見直し4選

「わからなかった」を分解しよう
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
見直し1 知らなかった単語を洗い出す
```
長文や設問で意味が取れなかった単語に印を付け、
**単語帳やノートに移して**次の模試までに覚え直す。

**3枚目**
```
見直し2 文法ミスは「知らない/見落とし」で分ける
```
**知識不足なのか、時制や主語の一致などの見落としなのか**を
分けて、対策を変える。

**4枚目**
```
見直し3 長文の設問は「根拠の1文」に線を引く
```
正解した問題でも、**答えの根拠になった本文の1文**に線を引き、
根拠を説明できるか確かめる。

**5枚目**
```
見直し4 大問ごとの時間配分を振り返る
```
どの大問に何分かけたかを書き出し、
**時間を使いすぎた大問**を次回の配分に反映する。

### 3. 締め
```
まとめ
①知らなかった単語を洗い出して覚え直す
②文法ミスを「知らない/見落とし」で分ける
③長文の設問は根拠の1文に線を引く
④大問ごとの時間配分を振り返る

保存して、模試の見直しのときに見返してね📌
英語の対策情報も知りたい人はフォローで待っててね。
```
