```
「その書き出し、実は減点対象かも」総合型選抜の志望理由書、やりがちなNGな書き出し5つをチェック🙅

　→ 校風だけを理由にすると、他大学にも当てはまる一般論に見えてしまう。その校風のどの制度が自分の学びに直結するかまで書く

② 「〇〇学部志望動機」をそのままタイトル的に書き出す
　→ 提出書類の設問欄をそのまま繰り返しても内容にならない。最初の一文から自分の言葉で始める

③ 「少子高齢化が進む中〜」など社会一般論からスタートする
　→ ニュースの要約から入ると自分の経験が後回しになり、読み手の印象に残りにくい

　→ 大学は貢献してもらう場ではなく学ぶ場。何を学びたいかを軸にした言い回しに変える
```

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**(2026-09-23は日にちが奇数のため)

### 1. 表紙
```
総合型選抜 面接
この4つの質問だけは準備して

台本を覚えるより、質問の"型"を知ろう
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
Q1. 志望理由を教えてください
```
書類に書いた内容を**一言で言い切る**練習をしておく。
長く話すより、最初の一文で結論を伝える方が印象に残る。

**3枚目**
```
Q2. 高校時代に力を入れたことは?
```
**エピソード**だけで終わらせず、そこから
**何を学んだか**までセットで話せるようにする。

**4枚目**
```
Q3. 入学後は何を学びたいですか?
```
「頑張りたい」ではなく、**ゼミ名や授業名**など
具体的な単語を1つは入れて語れるようにしておく。

**5枚目**
```
Q4. 他に受けている大学はありますか?
```
正直に答えつつ、最後は**志望校への熱意**に
話を戻して締めくくる練習をしておく。

### 3. 締め
```
まとめ
①志望理由は一言で言い切れるように練習する
②力を入れたことは学びとセットで話す
③入学後にやりたいことは具体的な単語で語る
④併願校を聞かれても志望校への熱意に戻す

保存して、面接前に見返してね📌
総合型選抜の対策情報も知りたい人はフォローで待っててね。
```
