## フィード下書き(カルーセル)

**テーマの性質**: 権威感のある「やるべきことリスト」 → **テンプレC(紺色×白アイコン)**

### 1. 表紙
```
総合型選抜

```
キャッチコピー: 「付け焼き刃の対策で、後悔しないために。」

### 2. 中面(1テーマ1枚・チェックリスト型)

**2枚目**
```
□ 志望理由を「一言」で言えるか確認する
きみの言葉で30秒にまとめられないなら、
まだ理解が浅いサイン。
```

**3枚目**
```
□ 高校時代の経験を「数字」で語れるか
「頑張った」だけでは伝わらない。
回数・期間・結果を添えて具体化しよう。
```

**4枚目**
```
□ 逆質問を3つ用意しておく
面接の最後に聞かれる逆質問は
きみの本気度を見せる最後のチャンス。
```

**5枚目**
```
□ 想定外の質問への「間」を練習する
答えに詰まった時、黙り込まず
「少し考えさせてください」と言えるか。
```
