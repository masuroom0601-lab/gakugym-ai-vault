## リール台本(英検語彙・熟語シリーズ)

**タイトル**: 動詞は使い分けで覚える

**表紙のテーマ文言**: 英検準2級

### 本編(前半5項目・Canva用)

1. borrow と lend
   - 補足: borrow は「借りる」、lend は「貸す」。自分に来るのが borrow、相手に渡すのが lend

2. say と tell
   - 補足: say は「言う(内容)」、tell は「人に伝える」。tell のあとには人が来るよ

3. listen と hear
   - 補足: listen は「聞こうとして聞く」、hear は「自然に聞こえる」。意識があるかどうかが違い

4. bring と take
   - 補足: bring は「持ってくる」、take は「持っていく」。話し手のほうへ来るなら bring

5. learn と teach
   - 補足: learn は「学ぶ」、teach は「教える」。自分が受け取るか、相手に渡すかで選ぼう

```
6. win と beat
 → win は「(試合・賞に)勝つ」、beat は「(相手に)勝つ」。beat のあとには相手が来るよ

7. lose と miss
 → lose は「失う・負ける」、miss は「逃す・恋しく思う」。miss the bus(バスに乗り遅れる)はよく出る形

8. expect と hope
 → expect は「起こると予想する」、hope は「そうなってほしいと願う」。根拠があるのが expect

9. job と work
 → job は「(1つ2つと数えられる)職・仕事」、work は「(数えられない)作業・仕事」。a job は言えるけど a work とは言わないよ

10. look と watch
 → look は「目を向ける」、watch は「動くものをじっと見る」。watch TV、look at a picture と覚えよう

似た動詞は「日本語訳」ではなく「だれがどうする場面か」で区別すると、4択でも迷いにくくなるよ✨
```

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```

```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 放送前に「選択肢」を先読みする
```
選択肢が**印刷されている問題**は、放送前に目を通そう。
聞くべき**ポイント**が絞れて、聞き逃しが減る。

**3枚目**
```
2 選択肢の「違い」に印をつける
```
似た選択肢は**違う部分**だけが答えのカギ。
**数字・場所・人**など、違いに**〇**をつけて待とう。

**4枚目**
```
3 質問は「最初の一語」を聞き逃さない
```
**What / Where / Why** など、疑問詞で**答えの型**が決まる。
質問が流れたら、まず**最初の一語**に集中しよう。

**5枚目**
```
4 わからなくても「引きずらない」
```
1問に**悩みすぎる**と、次の問題を**聞き逃す**。
迷ったら**直感**で選び、すぐ次の**先読み**へ切り替えよう。

### 3. 締め
```
まとめ
①放送前に「選択肢」を先読みする
②選択肢の「違い」に印をつける
③質問は「最初の一語」を聞き逃さない
④わからなくても「引きずらない」

保存して、英検リスニングの練習に使ってね📌
```
