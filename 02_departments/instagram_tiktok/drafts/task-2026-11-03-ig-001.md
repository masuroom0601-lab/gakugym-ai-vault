## リール台本(英検語彙・熟語シリーズ)

**タイトル**: 似た熟語、知ってる?

**表紙のテーマ文言**: 英検3級

### 本編(前半5項目・Canva用)

1. look for と look at
   - 補足: look for は「探す」、look at は「見る」。for は「求めて」のイメージ

2. get on と get off
   - 補足: get on は「乗る」、get off は「降りる」。off は「離れる」イメージ

3. talk to と talk about
   - 補足: talk to は「〜に話しかける」、talk about は「〜について話す」

4. be good at と be good for
   - 補足: be good at は「〜が得意」、be good for は「〜に良い」。at は得意な一点を指すよ

5. get up と wake up
   - 補足: get up は「起き上がる」、wake up は「目が覚める」。目覚めてから起きるのが順番

## キャプション(投稿時にそのままコピペする本文)

```
3級の熟語、「前置詞が違うだけで意味が変わる…」って迷ったことない?🤔
動画の続き(6〜10個目)はここでチェックしてね👇

6. put on と wear
 → put on は「着る(動作)」、wear は「着ている(状態)」。着る瞬間か、着ている最中かで使い分けるよ

7. ask for と ask about
 → ask for は「〜を求める」、ask about は「〜について尋ねる」。for は「欲しいものを求める」イメージ

8. come from と come back
 → come from は「〜出身だ」、come back は「戻ってくる」。I come from Japan. は自己紹介で超よく使う形

9. be late for と be in time for
 → be late for は「〜に遅れる」、be in time for は「〜に間に合う」。for のあとには授業や電車などが来るよ

10. sit down と stand up
 → sit down は「座る」、stand up は「立ち上がる」。down と up が動きの向きを教えてくれるよ

熟語は「動詞+前置詞」をセットで見て、前置詞のイメージ(for=求めて、at=一点、off=離れる)と一緒に覚えると、4択でも選びやすくなるよ✨

保存して、熟語の復習に使ってね📌
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 入室したら「あいさつ」から元気よく
```
入室時の**あいさつ**と**笑顔**で、第一印象が決まる。
声が小さいと**自信がなさそう**に見えるので注意。

**3枚目**
```
2 音読は「意味のかたまり」で区切る
```
一語ずつ読むと**不自然**に聞こえる。
**意味のかたまり**ごとに区切って、**はっきり**読もう。

**4枚目**
```
3 聞き取れなければ「聞き返す」
```
黙ってしまうのが**いちばんの失点**。
**Pardon?** と聞き返せば、**もう一度**チャンスがある。

**5枚目**
```
4 答えは「一言」で終わらせない
```
Yes / No だけで止めずに、**理由**を一文添えよう。
**主語と動詞**のそろった文で答えるのが基本。
