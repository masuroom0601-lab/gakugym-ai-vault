## キャプション(投稿時にそのままコピペする本文)

```
「その小論文、感想文になってない?」総合型選抜の小論文、やりがちなNGな書き方5つをチェック✍️

① テーマからズレた具体例だけを並べる
　→ 出題テーマに関係のない一般論やエピソードを並べると、採点者に論点がぼやけて見える

② 「〜と思う」で締める感想文口調で終わる
　→ 小論文は主張とその根拠を示す文章。主観的な感想で終わると論理的な文章に見えない

③ 序論・本論・結論の型を作らず書き始める
　→ 思いつくまま書き始めると話が脱線しやすい。先に構成をメモしてから書き始める

④ 一文が長く主語と述語がねじれる
　→ 一文に情報を詰め込みすぎると、読み返したときに主語と述語が合わなくなりやすい

⑤ 結論を書き切れずに時間切れで終わる
　→ 制限時間内に結論まで書き切れるよう、下書き段階で時間配分を決めておく

保存して、小論文を書く前に見返してね📌
総合型選抜の対策情報も知りたい人はフォローで待っててね!

#総合型選抜 #小論文 #NG例 #受験勉強 #学ジム
```

## フィード下書き(カルーセル)

**使用テンプレート: 図解で覚えるシリーズ**(2026-09-24は日にちが偶数のため)

### 1. 表紙
```
総合型選抜
活動報告書 ネタの見つけ方
```

### 2. 中面(1テーマ1枚・図解型)

**2枚目**
```
STEP1 部活・委員会だけでなく授業内の探究活動も洗い出す
```
「部活の実績」だけに絞らず、探究学習やゼミ発表など
授業内での取り組みも活動報告書のネタになる。

**3枚目**
```
STEP2 「困った→試した→変わった」の流れで思い出す
```
成果だけでなく、うまくいかなかった時期に
何を試して何が変わったかを思い出すとエピソードになる。

**4枚目**
```
STEP3 数字や役割名など具体的な言葉を1つ添える
```
「頑張った」だけでなく、「部長として30人をまとめた」
のように具体的な言葉を1つ入れると説得力が増す。

**5枚目**
```
STEP4 大学で学びたいことと1つ共通点を見つける
```
経験を語って終わらせず、その経験が志望学部での
学びとどうつながるかを1つ添えて締めくくる。

### 3. 締め
```
まとめ
①部活だけでなく授業内の探究活動もネタになる
②「困った→試した→変わった」の流れで経験を思い出す
③数字や役割名など具体的な言葉を1つ添える
④大学で学びたいこととの共通点を1つ見つける

保存して、活動報告書を書く前に見返してね📌
総合型選抜の対策情報も知りたい人はフォローで待っててね。
```
