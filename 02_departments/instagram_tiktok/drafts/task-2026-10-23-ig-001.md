## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
英単語、
覚えたのに忘れる?

忘れないための4つの復習コツ
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 覚えた翌日に必ず1回見直す
```
人は**覚えた翌日**にいちばん多く忘れてしまう。
翌日の**ほんの数分**の見直しが、記憶を大きく左右する。

**3枚目**
```
2 1回で完璧を目指さず何周もする
```
1回で全部覚えようとすると、時間がかかって続かない。
**短時間で何周も回す**ほうが、結果的に定着しやすい。

**4枚目**
```
3 間違えた単語だけにしるしをつける
```
全部を同じ強さで復習するのは非効率。
**間違えた単語だけ**にチェックを入れて、次はそこを重点的に見る。

**5枚目**
```
4 例文ごと声に出して覚える
```
単語だけを眺めても、使い方までは身につきにくい。
**例文ごと音読**すると、意味と使い方がセットで残る。

### 3. 締め
```
まとめ
①覚えた翌日に必ず1回見直す
②1回で完璧を目指さず何周もする
③間違えた単語だけにしるしをつける
④例文ごと声に出して覚える

保存して、単語を覚えるときに見返してね📌
英語の勉強法をもっと知りたい人はフォローで待っててね。
```
