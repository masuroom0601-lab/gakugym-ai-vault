## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
模試の結果
見るべきポイント4つ

判定だけで終わらせない
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
ポイント1 大問ごとの得点率を見る
```
合計点だけでなく、**大問・分野ごとの得点率**を確認する。
どこで点を落としたかが分かれば、次にやることが決まる。

**3枚目**
```
ポイント2 時間配分を振り返る
```
解き終わらなかった問題は、**実力不足か時間不足か**を分けて考える。
対策がまったく変わる。

**4枚目**
```
ポイント3 ケアレスミスを数える
```
知識不足のミスと**ケアレスミス**を分けて数える。
ケアレスミスは見直しの手順で減らせる。

**5枚目**
```
ポイント4 前回との変化を比べる
```
1回の判定に一喜一憂せず、**前回の自分との差**を見る。
伸びた点・下がった点が、次の模試までの課題になる。

### 3. 締め
```
まとめ
①大問ごとの得点率を見る
②時間配分を振り返る
③ケアレスミスを数える
④前回との変化を比べる

保存して、模試が返ってきたら見返してね📌
受験生活のコツをもっと知りたい人はフォローで待っててね。
```
