## リール台本(英検語彙・熟語シリーズ)

**タイトル**: なぜ英検の紛らわしい単語は何度も間違えるのか

**表紙のテーマ文言**: 英検準2級

### 本編(前半5項目・Canva用)

1. borrow と lend
   - 補足: 「借りる」が borrow、「貸す」が lend。向きで覚えよう

2. hear と listen
   - 補足: 自然に聞こえるのが hear、耳を傾けるのが listen

3. rob と steal
   - 補足: rob は「人・場所から奪う」、steal は「物を盗む」

4. raise と rise
   - 補足: raise は「〜を上げる」、rise は「上がる」。目的語の有無がカギ

5. affect と effect
   - 補足: affect は動詞「影響する」、effect は名詞「影響・効果」

6. win と beat
 → win は「試合に勝つ」、beat は「相手を負かす」。beat の後ろには相手(人・チーム)が来るよ

7. bring と take
 → 相手のところへ持って「くる」のが bring、相手から離れて持って「いく」のが take

8. beside と besides
 → beside は「〜のそばに」、besides は「〜に加えて」。s がつくと意味が変わるよ

9. economic と economical
 → economic は「経済の」、economical は「経済的な(お得な)」

10. lose と miss
 → lose は「失う・負ける」、miss は「逃す・恋しく思う」

違いは「文の形」とセットで覚えると、4択問題でも迷いにくくなるよ✨

**2枚目**
```

```
筆記の最初に出る**語彙問題**は、問題数が多いゾーン。

**3枚目**
```
2 リスニングは「先読み」に慣れる
```
放送前に**選択肢をざっと読む**クセをつける。
**場面と質問**を予想できると、聞き取りがラクになる。

**4枚目**
```
3 長文は「設問から」読む
```
いきなり本文を読まず、**設問を先にチェック**。
**探す情報**が分かれば、読む時間が**短くなる**。

**5枚目**
```
4 英作文は「型」を決めておく
```
**理由を2つ**書く型など、**自分の型**を用意する。
本番で**迷わず**書けて、**ミスも減らせる**。
