**タイトル**: 英単語を高速で覚える方法10選

**表紙のテーマ文言**: 英語(配色は英語=黄色。色は益田さんが手動適用)

### 本編(Canva用・前半5項目)

**1.** メイン文: `1. 1回で覚えようとせず、何周も回す前提で進める`
補足文: `忘れて当たり前。繰り返すほど記憶に残るよ`

**2.** メイン文: `2. 1日の学習量を決めて、毎日短時間でふれる`
補足文: `週末にまとめてより、毎日少しずつの方が定着しやすいよ`

**3.** メイン文: `3. 1周目は「見て意味が分かるか」だけを確認する`
補足文: `書いて覚える前に、まず全体をざっと回そう`

**4.** メイン文: `4. 声に出して、音と一緒に覚える`
補足文: `目と耳と口を使うと、思い出しやすくなるよ`

**5.** メイン文: `5. 覚えていない単語だけにチェックをつける`
補足文: `分かる単語に時間を使わないのが、高速化のコツ`

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
古文単語は
"現代語と同じ"が落とし穴

意味が変わった4語を先に押さえよう
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 「ありがたし」=ありがとう、ではない
```
古文の「ありがたし」は**「めったにない」**という意味。
「有り難し(存在しにくい)」と考えると覚えやすい。

**3枚目**
```
2 「やがて」=あとで、ではない
```
古文の「やがて」は**「そのまま・すぐに」**という意味。
現代語の「やがて(そのうち)」と混同しないよう注意。

**4枚目**
```
3 「かなし」=悲しい、だけではない
```
「かなし」には**「いとしい・かわいい」**という意味もある。
文脈で、悲しいのか愛しいのかを判断しよう。

**5枚目**
```
4 「おどろく」=びっくりする、ではない
```
古文の「おどろく」は**「はっと気づく・目を覚ます」**という意味。
驚きの感情だけで訳すと、文意がずれやすい。

### 3. 締め
```
まとめ
①「ありがたし」=めったにない
②「やがて」=そのまま・すぐに
③「かなし」=いとしい(悲しいだけではない)
④「おどろく」=はっと気づく・目を覚ます

保存して、古文単語を覚える前に見返してね📌
受験勉強のコツをもっと知りたい人はフォローで待っててね。
```
