## リール台本(スマホ習慣セルフチェック形式)

**タイトル**: スマホ依存度チェック

**表紙のテーマ文言**: スマホ依存対策

**チェック項目**:
1. 勉強机にスマホを置いたまま始めている
2. 「5分だけ」と開いて、気づけば30分たっている
3. 通知が鳴ると、つい手が伸びてしまう
4. 勉強の合間の休憩が、いつもSNSになっている
5. 調べ物のつもりが、動画を見てしまった
6. スマホが見当たらないと、落ち着かない

**診断ライン**: 3個以上当てはまったら、スマホに"使われている"状態かも

## キャプション(投稿時にそのままコピペする本文)

```
3個以上当てはまった人へ📱 それ、意志が弱いからじゃないよ。スマホに負けない「仕組み」で解決できます。期末テスト前に今すぐ試してね!

【チェック項目ごとの改善法】

1. 机にスマホを置いたまま始める
 → 勉強前に別の部屋かカバンの中へ。目に入らない場所に置くのが一番効くよ

2. 「5分だけ」が30分になる
 → 開く前にタイマーをセット。終わる時間を先に決めておくと止めやすいよ

3. 通知につい手が伸びる
 → 勉強中は通知オフ(集中モード・おやすみモード)に。スクリーンタイムで時間帯を固定しておくと楽だよ

4. 休憩がSNSになる
 → 休憩は「立つ・水を飲む・ストレッチ」など、スマホを使わないメニューを先に決めておこう

5. 調べ物のつもりが動画に…
 → 調べ物は参考書・電子辞書を優先。どうしても使うなら、SNSアプリはホームから外しておくと開きにくいよ

6. スマホが見えないと落ち着かない
 → 最初は30分だけ離れる練習から。慣れたら60分、90分と少しずつ伸ばそう

私もスマホ依存から抜け出して、GMARCHに合格できたよ。大事なのは根性じゃなくて環境づくり✨

保存して、勉強前に見返してね📌
スマホ対策をもっと知りたい人はフォローで待っててね!

#スマホ依存 #スマホ対策 #受験勉強 #大学受験 #高校生
```

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**


### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 単語は「間違えたものだけ」を回す
```
全部をやり直すと時間が足りない。**間違えた単語**に印をつけて、そこだけ**繰り返す**。
**覚えている単語**は思い切って飛ばす。

**3枚目**
```
2 文法は「ワークの間違い」を解き直す
```
新しい問題集に手を出さず、**学校のワーク**を**もう一周**。
**間違えた問題**は、**なぜ間違えたか**を一言メモしておく。

**4枚目**
```
3 教科書本文は「音読+和訳」で確認する
```
**音読**しながら、**意味が言えるか**をチェック。
詰まった文は**文構造(SとV)**を確認して覚え直す。

**5枚目**
```
4 ケアレスミスは「見直し手順」で防ぐ
```
**三単現のs・時制・単数複数**など、**自分がよくやるミス**をリスト化する。
解答後は**そのリスト順**に見直す。

### 3. 締め
