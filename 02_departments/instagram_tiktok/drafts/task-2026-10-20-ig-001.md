## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
古文の助動詞、
丸暗記でつまずいてない?

覚えやすくなる4つのコツ
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 意味と「接続」をセットで覚える
```
意味だけ覚えても、**識別問題で迷う**原因になる。
**どの形に続くか(接続)**まで一緒に覚えておく。

**3枚目**
```
2 活用表は声に出してリズムで覚える
```
目で眺めるだけでは定着しにくい。
**声に出して唱える**と、順番ごと頭に残りやすい。

**4枚目**
```
3 意味がいくつもある助動詞から優先する
```
「る・らる」「む」「べし」など、**意味が複数ある助動詞**はテストの定番。
**まずここを固める**と、点につながりやすい。

**5枚目**
```
4 例文ごと覚えて訳し分ける
```
単独の意味より、**例文の中での使われ方**で覚える。
**前後の言葉**を手がかりに、意味を判断する練習をする。

### 3. 締め
```
まとめ
①意味と「接続」をセットで覚える
②活用表は声に出してリズムで覚える
③意味がいくつもある助動詞から優先する
④例文ごと覚えて訳し分ける
```
