## キャプション(投稿時にそのままコピペする本文)

```
「その年号、丸暗記だけで大丈夫?」中間テスト前の世界史、この5つで乗り切ろう🌍

① 年号は「ゴロ+出来事の因果関係」でセットに覚える
　→ 年号だけ覚えても、なぜその出来事が起きたかを知らないと応用問題で答えられない
② 地図と一緒に覚えて出来事の場所を混同しない
　→ 場所のイメージがないと、似た地域の出来事を取り違えやすい
```

## フィード下書き(カルーセル)

**使用テンプレート: 通常版**(2026-09-21は日にちが奇数のため)

### 1. 表紙
```
化学、それ計算ミスかも
```
キャッチコピー: 「中間テスト前に絶対見直したい4つのポイント」

### 2. 中面(1テーマ1枚・解説型)

**2枚目**
```
mol計算での単位のかけ間違い
```
「mol→g」「g→mol」の変換を焦って
**逆にかけてしまう**ミスが非常に多い。
単位を書きながら計算する癖をつけると防げる。

**3枚目**
```
化学反応式の係数を合わせ忘れる
```
反応式の**係数比がそのままmol比**になる
ことを意識せず、係数を合わせないまま
計算して失点するケースが多い。

**4枚目**
```
有効数字の桁数間違い
```
計算自体は合っていても、**指定された
有効数字**で答えを丸め忘れて減点される。
問題文の条件を先に確認する癖をつける。

**5枚目**
```
イオン式の符号(+/-)の書き忘れ
```
化学式は合っていても**電荷の符号を
書き忘れる**だけで別の意味になり不正解に
なる。書いた後に符号だけ見直す時間を作る。

### 3. 締め
```
まとめ
①mol計算は単位を書きながら計算しかけ間違いを防ぐ
②反応式は係数を合わせてからmol比を使う
③有効数字は問題文の指定桁数で丸める
④イオン式は電荷の符号まで書き忘れずに確認する

保存して、テスト前日に見返してね📌
他の科目のよくあるミスも知りたい人はフォローで待っててね。
```
