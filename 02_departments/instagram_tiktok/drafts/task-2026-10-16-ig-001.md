## フィード下書き(カルーセル)

**使用テンプレート: 通常版**

### 1. 表紙
```
古文の助動詞、
全部暗記してない?

意味が取れるようになる4つのコツ
```

### 2. 中面(4ページ、1テーマ1枚・チェックリスト型)

**2枚目**
```
1 まず「接続」で仲間分けする
```
助動詞は、**前にくる活用形**で整理できる。
未然形接続・連用形接続など、**グループで見る**と覚える量が減る。

**3枚目**
```
2 複数の意味を持つものは「見分け方」とセットで覚える
```
**「る・らる」「す・さす」**などは意味が複数ある。
意味の一覧だけでなく、**どんな文脈でその意味になるか**を一緒に覚える。

**4枚目**
```
3 活用表は「書いて」身につける
```
見て眺めるだけでは、いざという時に出てこない。
**白紙に書き出す練習**で、抜けている所が分かる。

**5枚目**
```
4 例文ごと音読して覚える
```
助動詞だけを単体で覚えない。
**短い例文ごと声に出す**と、読解の中で自然に使える形で定着する。

### 3. 締め
```
まとめ
①接続で仲間分けする
②複数の意味は見分け方とセットで覚える
③活用表は書いて身につける
④例文ごと音読して覚える

保存して、助動詞を復習するときに見返してね📌
古文の勉強法をもっと知りたい人はフォローで待っててね。
```
