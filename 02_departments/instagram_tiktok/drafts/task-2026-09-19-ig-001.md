## キャプション(投稿時にそのままコピペする本文)

```
「その句法、瞬時に訳せる?」中間テスト前の漢文、この5つで乗り切ろう📜

① 句法は「意味」より先に「形」で覚える
　→ 「〜せしむ」のような形を見た瞬間に句法名が浮かぶまで反復すると、初見の文でも対応しやすい
② 重要語は音読みと訓読みをセットで覚える
　→ 読み方だけ覚えても意味が出てこないと得点にならない。音・訓・意味を1セットで覚える
③ 返り点のパターンは書き下し文で確認する
　→ 返り点だけを目で追うより、書き下し文と照らし合わせる方が読む順番が定着しやすい
④ 頻出漢字は同じ漢字で意味が変わる例をリスト化する
　→ 「之」「而」など多義語は、文脈ごとの意味を並べて覚えると混同しにくい
⑤ 前日夜と当日朝に句法一覧を高速で見返す
　→ 寝る前と起きた直後は記憶が整理されやすいゴールデンタイム

保存して、テスト前日にもう一度見返してね📌
```

### 2. 中面(1テーマ1枚・解説型)

**2枚目**
```
地図記号と統計資料の対応を混同する
```
地図記号や雨温図はセットで覚えないと、
資料問題で符号だけ見て早合点しやすい。

**3枚目**
```
気候区分と農業・産業の結びつけが曖昧
```
気候だけ覚えても、そこから生まれる
産業まで結び付けないと応用問題に対応できない。

**4枚目**
```
用語を地名だけで覚えて位置が答えられない
```
白地図で位置を確認しながら覚えないと、
地図問題で失点しやすい。

**5枚目**
```
統計資料の「最新の傾向」を追っていない
```
教科書のグラフは経年で変わるため、
最新の傾向を意識しないと誤答しやすい。

### 3. 締め

```
②気候区分と産業を結びつけて覚える
```
