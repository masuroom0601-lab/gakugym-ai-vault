## 固定投稿(リール)用の告知文(ドラフト)

**タイトル(表紙)**: 英検特化にします

**本文(動画内キャプション相当・投稿文)**
```
これまで「スマホ対策」を軸に発信してきたけど、
思い切って英検対策に全振りすることにした📚

理由はシンプルで、毎日出してる英検クイズの反応が
他のどの投稿よりも圧倒的に良かったから。
「役に立つものを、ちゃんと役に立つ形で届けたい」と思ったら、
これが一番だった。

これからは、
・毎日1問、英検クイズ(3級〜準1級)
・紛らわしい単語・熟語シリーズ
・級別の対策法(リスニング・ライティング・面接)
を中心に発信していく。

スマホ対策で繋がってくれたきみも、今の自分に合う級の
投稿から見てもらえたら嬉しい。保存して、毎日チェックしてね。

#英検 #英語学習 #受験英語
```

**備考**: 固定投稿として一定期間(1〜2週間程度を推奨)トップに固定し、
移行期間中に見てもらえるようにする。期間が終わったら固定を外してよい。

## ストーリーズ用の告知文(ドラフト、2枚構成)

**1枚目(テキストのみ、シンプルに)**
```
お知らせ📢
これからは英検対策に
全力を出します
```

**2枚目(質問スタンプ付きを推奨)**
```
毎日1問、英検クイズ(3級〜準1級)を
中心に発信していくよ!

[質問スタンプ] 今、英検何級の対策してる?
→ 3級 / 準2級 / 2級 / 準1級
```

**備考**: 質問スタンプの回答データは今後のコンテンツ企画(どの級の需要が
高いか)の参考にできる。ストーリーズは投稿後24時間で消えるため、ハイライトに
「英検特化のお知らせ」として残しておくことを推奨。

## ハイライトの再編(参考、益田さん作業)
既存のハイライト構成が科目別・スマホ対策別になっている場合は、英検の級別
(3級/準2級/2級/準1級)に再編することを推奨する。移行告知のストーリーズも
専用ハイライトとして残すとよい。
