## リール台本(スマホ習慣セルフチェック形式)

**タイトル**: ご褒美依存度チェック

**チェック項目**:
1. 勉強前にまずお菓子を用意する
2. 休憩のつもりが1時間になる
3. ガチャや課金のことが頭に浮かぶ
4. 地味な暗記が退屈でたまらない
5. 勉強しても達成感が薄く感じる
6. 新しい参考書を買うと満足する

**診断ライン**: 3個以上当てはまったあなたは"ドーパミン中毒"かも

## 投稿用キャプション(投稿時にそのままコピペする本文)

```
3個以上当てはまった人、"ドーパミン中毒"かも?
(医学的な診断じゃなく、刺激に慣れすぎてるかものセルフチェックです)

意志が弱いんじゃない。強い刺激に慣れた脳は、地味な勉強が退屈に感じるだけ。仕組みで刺激を減らせば戻せます。

【改善法】
1. お菓子を先に用意する → ご褒美は「今日のノルマの後」に固定。机には水だけ
2. 休憩が伸びる → 休憩はタイマー10分。動画やゲームは休憩に使わず、散歩やストレッチに
3. ガチャ・課金が浮かぶ → ゲームアプリは平日だけ整理して、通知オフ+ホーム画面の外へ
4. 暗記が退屈 → 25分を1セットにして「終わったら○」をつける。小さく終わらせる
5. 達成感が薄い → 勉強量を数字で記録。ページ数や問題数を毎日メモ
6. 参考書を買って満足 → 新しく買う前に、手元の1冊を1周してから

刺激を減らす=我慢ではなく、仕組みづくり。できるところから1つだけでOKです。

あとで見返せるよう保存、続きはフォローで!

#スマホ依存 #ドーパミン #受験生 #勉強習慣 #集中力
```
