## リール台本(スマホ習慣セルフチェック形式)

**タイトル**: 休日スマホ溶かしチェック

**チェック項目**:
1. 休日は昼までふとんでスマホを見る
2. 気づくと半日スマホで終わっている
3. 勉強開始がいつも夕方になる
4. 「午前中にやる」と決めて守れない
5. 休日のスクリーンタイムが平日より長い
6. 日曜の夜に「何もしなかった」と落ち込む

**診断ライン**: 3個以上当てはまったら、スマホに"使われている"状態かも

## 投稿用キャプション(投稿時にそのままコピペする本文)

```
休日、気づいたら半日スマホで消えていませんか?
それは意志の弱さではなく、休日の「仕組み」がないだけです。

▼チェック項目ごとの改善法
1. 昼までふとんでスマホ→充電器をふとんから離れた場所に置く。起きてスマホを取りに行く=体を起こす仕組みに
2. 半日が消える→スマホは「午前の勉強が終わるまで」別の部屋へ。タイマーロックアプリで開けなくするのも有効です
3. 開始が夕方→勉強を始める時刻を前日に決めて、机に教材を出しておく。座るだけの状態を作ります
4. 午前の約束を守れない→「午前中にやる」ではなく「9時に英語を15分」と時刻+内容まで具体化
5. 休日のほうが長い→スクリーンタイムの休日の数字をチェックして、動画・SNSアプリに1日の利用制限を設定
6. 日曜の夜に落ち込む→土曜の夜に「日曜の最初の1つ」だけ決める。小さく始めれば自己嫌悪も減ります

いきなり全部やらなくて大丈夫。まずは「充電場所を変える」だけ、今日から試してみてください。
保存して見返す・フォローして一緒に続けるのがおすすめです。

#受験生 #スマホ依存 #勉強習慣 #スマホ対策 #受験勉強
```
