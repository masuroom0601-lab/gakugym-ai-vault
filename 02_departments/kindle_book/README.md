## ファイル
- `manuscript/原稿_最新.docx` … これを常に最新のベースにする（変更履歴はすべて承諾済み）
- `manuscript/原稿_最新_直前の修正を変更履歴で表示.docx` … 直前の修正だけを変更履歴で見られる版
- `manuscript/原稿_益田さん編集版_2026-11-10.docx` … 益田さんが自分で編集した版（ベースの元）
- `figures/fig1〜8.png` … 本文に入れた図（図1〜図8）
- `tools/` … 原稿の自動修正に使ったスクリプト（変更履歴つき置換、縦書き用の数字変換、字下げ、図の作成）

## 決まっている編集ルール
- 読者への呼びかけは「君」で統一（「あなた」「皆さま」は使わない）。一人称は「僕」
- 恩師は「Ｎ先生」（全角大文字）。オンライン家庭教師の英語の先生
- 偏差値は「46→66」で統一し、ぼかさない
- 中学・高校は「早稲田佐賀」と実名で書く。**全寮制ではない**（「寮のある学校」「寮生活」と書く）
- 0点は「定期考査のある科目で0点」（学校史上初は事実）
- 著者が21歳であること・大学生であることは書かない（権威性のため）
- 学ジムの実績（合格者数など）は、実績がそろうまで書かない
- 学ジムは「無料コミュニティ」を入口として紹介し、個別指導は一文だけ添える
- 各章末に「この章のまとめ（3行）」と「今日からできるＮＡ（ネクストアクション）」を置く。ＮＡは益田さんが指導で使う言葉
- 強調のためだけの「」は使わない（会話・心の声・用語の初出・対比は残す）
- 「〜のだ。」を続けすぎない。大げさな言葉（最強・地獄・絶対的・真の など）を重ねない
- 心理学の説明は研究で分かっている範囲で書く（自我消耗は「疲れているときほど誘惑に負けやすい」程度に）
- 相談窓口のページは載せない

## 縦書きの表記ルール（tools/normalize.py）
- 1けたの数字: 全角（１つ、第５章）
- 2けたの数字: 縦中横（46、25分）
- 3けた以上・小数: 全角（１００語、２０１６年、０．３パーセント）
- 短い英大文字（A君、NA、SNS、IT）: 全角。YouTube などの英単語と参考文献はそのまま
- ％は全角、「⁈」は「！？」
- 本文の段落は1字下げ。「」で始まる会話・見出し・箇条書き・図・参考文献は字下げしない
