## 先に知っておいてほしいこと
「ホスティングは無料」ですが、「独自ドメインの取得」自体は実費(年額)がかかります
(README/brand-guide.mdの「ドメイン代等の実費のみ許容」に該当する支出です)。
`.com`や`.jp`なら年間1,000〜3,000円程度が目安ですが、レジストラ・TLDにより変わるので
購入前に必ず金額を確認してください。

## 前提条件
- ドメインレジストラ(お名前.com、Google Domains後継のSquarespace Domains、
  Cloudflare Registrar等)でアカウントを作成できること
- GitHubリポジトリ `gakugym-ai-vault` の管理者権限

## 手順

### 1. ドメインを取得する
お好きなレジストラで、学ジムの独自ドメイン(例: `gakugym.com` / `gakugym.jp` 等、
空いているもの)を購入する。

### 2. GitHub Pagesを有効化する
1. リポジトリの Settings → Pages を開く
2. Source: 「Deploy from a branch」、Branch: `main` / Folder: `/docs` を選択して保存
3. しばらくすると `https://<GitHubユーザー名>.github.io/gakugym-ai-vault/` で
   サイトが公開される(この時点ではまだデフォルトドメインでの公開)

### 3. カスタムドメインを設定する
1. 同じPages設定画面の「Custom domain」欄に、取得したドメインを入力して保存する
   - このリポジトリでは `docs/` フォルダをそのままPagesの公開元にしているため、
     保存すると自動的に `docs/CNAME` というファイルがリポジトリに追加される
     (中身はドメイン名1行のみ)
2. レジストラ側のDNS管理画面で、以下のいずれかを設定する:
   - **ルートドメイン(例: `gakugym.com`)を使う場合**: Aレコードを4つ追加し、
     GitHub PagesのIPアドレスを指定する
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
     (最新の推奨IPはGitHub公式ドキュメントで必ず確認すること)
   - **サブドメイン(例: `www.gakugym.com`)を使う場合**: CNAMEレコードで
     `<GitHubユーザー名>.github.io` を指定する
3. DNSの反映には数分〜数時間かかることがある。反映後、Pages設定画面で
   ドメインの検証(緑のチェックマーク)がつくのを待つ
4. 検証が終わったら、「Enforce HTTPS」にチェックを入れる
   (SSL証明書はGitHubが自動発行してくれるので追加費用はかからない)

## 注意点
- `docs/CNAME` は基本的にGitHub側が自動生成するファイルなので、
  手動で編集・削除しないこと(消すとカスタムドメイン設定が外れる)
- `docs/dashboard/` (オフィスダッシュボード)も同じドメイン配下
  (`https://<独自ドメイン>/dashboard/`)で公開される。社内用ツールを
  一般公開したくない場合は、別途アクセス制限(Basic認証等)の検討が必要
  (GitHub Pages自体には標準のアクセス制限機能がないため、必要になったら
  Cloudflareの無料プランをかませてBasic認証を追加する等の対応を検討する)
