## 重要な注意点
ThreadsはInstagramと同じMeta社のサービスですが、**Instagram用に作ったアプリとは別に、Threads専用のMetaアプリを新規作成する必要があります**(共用不可)。

## 手順

1. **Meta for Developers** で「アプリを作成」
   - 用途(ユースケース)の選択画面で、**「Threads APIへのアクセス」**を選ぶ
   - アプリ名を入力(例:gakugym-threads)して作成

2. アプリのダッシュボードで、Threads APIの設定画面から**自分自身をテスターとして追加**
   - 追加すると、Threadsアプリ側(スマホ)に招待通知が届くので、承認する

3. 「ツール」→「Graph APIエクスプローラ」(またはThreads専用の認証フロー)で、以下の権限を要求してアクセストークンを取得:
   `threads_basic`, `threads_content_publish`

4. 取得した短期トークンを、長期トークン(**60日間有効**)に交換:
5. 自分のThreadsユーザーIDを取得:
6. GitHubの`gakugym-ai-vault`リポジトリのSecretsに登録:
   - `THREADS_ACCESS_TOKEN`: 手順4の長期トークン
   - `THREADS_USER_ID`: 手順5のID

## 注意点(Instagramより厳しい)
- 長期トークンの有効期限は**60日**。自動更新の仕組みがないと、2ヶ月に1回、手動でトークンを再発行する必要があります
- **この「60日ごとのトークン更新」を忘れると、ある日突然投稿が失敗するようになります**。統括担当のタスクとして「50日ごとにトークン更新をリマインドする」項目を追加しておくことを推奨します
- 投稿は1〜数枚の画像・動画・カルーセルに対応。動画は処理に時間がかかるため、コンテナ作成後30秒ほど待ってから公開する必要あり
